API Reference

Complete API documentation for QuoNic quantum programming framework.

Info

QuoNic supports 19 backends, 75 algorithms, and 3 real hardware platforms. All examples are bilingual (English/Chinese).

Quick Start

python 
from quonic import qgate, qshow
from quonic.gates import H, CX

qgate(H, 0)      # Hadamard on qubit 0
qgate(CX, 0, 1)  # CNOT: entangle qubits
qshow()           # Run and display

qgate()

qgate(gate, *qubits, **params)

Apply a quantum gate to specified qubits.

gateGate|strGate object or name string
*qubitsintQubit indices
**paramsfloatGate parameters (for parametric gates)

Grover Search

from quonic.algorithms import grover

result = grover("11", 2, shots=1024)
print(result.counts)  # {'11': ~1000}

VQE

from quonic.algorithms import vqe

hamiltonian = [(1.0, "ZZ"), (0.5, "XI")]
result = vqe(hamiltonian, n_qubits=2, maxiter=200)
print(f"Energy: {result.value}")

Smart Scheduler

from quonic import qshow

# Auto-selects best backend

Noise Mitigation

from quonic import zne

result = zne(circuit, noise=0.05, extrapolation="linear")
print(f"ZNE: {result.extrapolated:.3f}")

Error Correction

from quonic.qec import BitFlipCode, qec_round_trip

result = qec_round_trip(code="bit_flip", error_rate=0.01)
print(f"Logical error: {result.logical_error_rate:.4f}")

Machine Learning

from quonic.ml import QMLPipeline

pipeline = QMLPipeline(n_qubits=4, layers=3)
pipeline.fit(X_train, y_train, maxiter=100)
predictions = pipeline.predict(X_test)

ZX-Calculus

from quonic.zx import circuit_to_zx, optimize_zx, extract_circuit

graph = circuit_to_zx(circuit)
simplified = optimize_zx(graph)
optimized = extract_circuit(simplified)
