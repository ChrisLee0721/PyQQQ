# QuoNic 未来路线图

> 生成日期：2026-08-19
> 覆盖：短期（1-3 月）、中期（3-6 月）、长期（6-12 月）、愿景（1-3 年）

---

## 一、短期（1-3 月）

### 1.1 性能优化

| 项 | 描述 | 收益 |
|---|---|---|
| CuPy 多比特门向量化 | CX/CCX/SWAP/MCZ 用 tensordot 替换 Python 循环 | 真实电路 10x |
| Numba JIT 单比特门 | 对不方便向量化的门用 @njit 编译 | 5-10x |
| 稀疏矩阵支持 | 大电路用 CSR 格式存储密度矩阵 | 内存 10x |
| 门融合 (gate fusion) | 连续单比特门合并为一个矩阵 | 深电路 2-3x |

### 1.2 调度器增强

| 项 | 描述 | 收益 |
|---|---|---|
| GPU benchmark 学习 | 用 LocalCacheRegistry 记录 GPU 性能，自动调优 | 自适应 |
| 电路指纹 (circuit fingerprint) | 更精细的电路特征（门密度、参数化比例、纠缠深度）| 调度精度 |
| 后端健康检查 | 运行前检测后端可用性（GPU 内存、SDK 版本）| 错误预防 |
| 动态降级 | 运行时 OOM 自动降级到更小后端 | 鲁棒性 |

### 1.3 错误处理

| 项 | 描述 | 收益 |
|---|---|---|
| 智能错误提示 | "你用了 qif(0).then(CX,1)，但 CX 需要 2 个目标比特" | UX |
| 调试模式 | `qshow(debug=True)` 打印电路结构、调度决策、执行轨迹 | 可调试性 |
| 性能警告 | "你的电路有 30 个 qubit，建议用 MPS 方法" | 预防 |

## 五、技术债务

| 项 | 严重度 | 说明 |
|---|---|---|
| tensorcircuit numpy patch | 低 | 全局 patch，上游修复后可删 |
| cqlib 不是模拟器 | 低 | 委托 native，无独立 GPU |
| _i18n 文件过大 | 低 | 200+ 条消息，可按模块拆分 |
| qif 嵌套子电路 ≤4 qubit | 中 | 指数内存限制 |
| 参数化电路 IR 不支持符号 | 中 | 需要 Symbol 类 |
| 全局电路栈无并发 | 中 | 单进程全局状态 |

| **P2** | 量子机器学习框架 | 增长最快的用户群 |
| **P2** | 量子纠错完整支持 | 研究价值 |
| **P3** | 量子控制论 | 小众但高价值 |
