# 误差缓解演示

展示 QuoNic 的误差缓解功能，包括 ZNE（零噪声外推）和读出校准。

## 功能

1. **ZNE（零噪声外推）** — 通过电路折叠放大噪声，然后外推到零噪声
2. **读出校准** — 通过混淆矩阵校正测量误差
3. **堆叠** — ZNE + 读出校准组合使用，获得最佳结果

## 运行

```bash
python examples/error_mitigation/error_mitigation.py
```

## ZNE 原理

1. **电路折叠**：C → C(C†C)^k，噪声放大因子 λ = 2k+1
2. **外推**：对 (λ, 成功率) 数据拟合，外推到 λ=0
3. **拟合方法**：
   - 线性：y = a·λ + b
   - 指数：y = a·e^(-bλ) + c（门噪声主导时更准确）

## 读出校准原理

1. **准备已知状态**：依次准备 |00...0>, |00...1>, ..., |11...1>
2. **测量**：对每个状态采样，构建混淆矩阵 A
3. **校正**：p_true = A^(-1) · p_meas
