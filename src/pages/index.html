Why QuoNic?

Same circuit, fewer lines. QuoNic handles the complexity so you can focus on the quantum.

QuoNic — 3 lines
from quonic import qgate, qshow
from quonic.gates import H, CX

qgate(H, 0)
qgate(CX, 0, 1)
qshow()  # Auto-selects best backend
Qiskit — 10 lines
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure([0, 1], [0, 1])

simulator = AerSimulator()
result = simulator.run(qc, shots=1024).result()
print(result.get_counts())

Quick Start

pip install quonic
Run your first quantum circuit
from quonic import qgate, qshow
from quonic.gates import H, CX

qgate(H, 0)      # Hadamard on qubit 0
qgate(CX, 0, 1)  # CNOT: entangle qubits
qshow()           # Run and display
