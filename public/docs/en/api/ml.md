# Machine Learning

QuoNic provides quantum machine learning algorithms.

## Available Algorithms

- Quantum Neural Network (QNN)
- Quantum SVM
- Quantum GAN
- Quantum PCA
- Quantum Kernel Methods

## Usage

```python
from quonic.ml import qnn, qsvm

# Quantum Neural Network
result = qnn(data, labels, n_layers=2)

# Quantum SVM
result = qsvm(data, labels, kernel='quantum')
```
