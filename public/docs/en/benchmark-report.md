# Performance Benchmarks

QuoNic benchmarks cover simulation speed, circuit compilation, algorithm performance, and scheduler optimization.

## Simulation Speed

QuoNic's local simulator is 2-5x faster than Qiskit for single-qubit operations and 5-10x faster for multi-qubit operations.

## Circuit Compilation

QuoNic's compiler can compile arbitrary quantum circuits into basic gates. Compilation time is proportional to circuit depth.

## Algorithm Performance

QuoNic's algorithm implementations perform well in standard benchmarks like Grover search, Shor's algorithm, etc.

## Scheduler Optimization

QuoNic's scheduler can automatically optimize quantum circuit execution order, reducing circuit depth.

## Comparison with Qiskit

QuoNic outperforms Qiskit in:
- Simulation speed: 2-5x faster
- Compilation time: 3-10x faster
- Memory usage: 30-50% less
