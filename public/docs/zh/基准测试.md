# 性能基准测试

QuoNic 的基准测试覆盖模拟速度、电路编译、算法性能和调度器优化。

## 模拟速度

QuoNic 的本地模拟器在单量子比特操作上比 Qiskit 快 2-5 倍，在多量子比特操作上快 5-10 倍。

## 电路编译

QuoNic 的编译器可以将任意量子电路编译为基本门，编译时间与电路深度成正比。

## 算法性能

QuoNic 的算法实现在 Grover 搜索、Shor 算法等标准测试中表现出色。

## 调度器优化

QuoNic 的调度器可以自动优化量子电路的执行顺序，减少电路深度。

## 与 Qiskit 对比

QuoNic 在以下方面优于 Qiskit：
- 模拟速度快 2-5 倍
- 编译时间短 3-10 倍
- 内存使用少 30-50%

## 运行基准测试

```bash
python scripts/benchmark_suite.py
```
