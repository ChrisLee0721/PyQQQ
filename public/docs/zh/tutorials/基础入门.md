# 基础入门

学习 QuoNic 的基础知识：构建电路、运行电路、读取结果。

## 最简单的电路

```python
from quonic import qgate, qshow
from quonic.gates import H, CX

qgate(H, 0)      # 对 qubit 0 施加 Hadamard 门
qgate(CX, 0, 1)  # CNOT 门：控制=0，目标=1
qshow()           # 运行并显示结果
```

这会创建一个 Bell 态。`qshow()` 会在最佳可用后端上运行电路并打印结果。

## 理解量子比特

在 QuoNic 中，量子比特就是数字。`qgate(H, 0)` 对量子比特 0 施加 Hadamard 门。不需要创建电路对象，不需要管理量子比特寄存器。

```python
qgate(X, 0)      # Pauli-X（比特翻转）作用于 qubit 0
qgate(H, 1)      # Hadamard 作用于 qubit 1
qgate(CX, 0, 1)  # CNOT：控制=0，目标=1
```

## 测量和结果

`qshow()` 执行电路并显示测量结果：

```python
from quonic import qgate, qshow
from quonic.gates import H

qgate(H, 0)  # 创建叠加态
qshow()       # 测量并显示
```

输出示例：
```
backend: native | shots: 1024
Result:
  |0>     512  ( 50.0%)  ####################
  |1>     512  ( 50.0%)  ####################
```

## 使用不同的后端

QuoNic 支持多种量子后端：

```python
qshow(backend='native')   # 本地模拟器
qshow(backend='qiskit')   # IBM Qiskit
qshow(backend='cirq')     # Google Cirq
```

## 重置量子态

使用 `reset()` 清除所有量子比特：

```python
from quonic import qgate, qshow, reset

qgate(H, 0)
reset()        # 清除所有量子比特
qgate(X, 0)    # 重新开始
qshow()
```
