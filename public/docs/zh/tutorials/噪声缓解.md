# 噪声缓解

学习如何处理量子噪声，提高量子计算的可靠性。

## 理解量子噪声

量子噪声是量子计算的主要挑战。噪声会导致量子态退相干，影响计算结果。

```python
from quonic.noise import noise_model

# 创建噪声模型
model = noise_model(error_rate=0.01, noise_type='depolarizing')
print(f"Noise model: {model}")
```

## 噪声类型

### 比特翻转噪声

比特翻转噪声会随机翻转量子比特：

```python
from quonic.noise import noise_model

model = noise_model(error_rate=0.05, noise_type='bit_flip')
```

### 相位翻转噪声

相位翻转噪声会随机翻转量子相位：

```python
model = noise_model(error_rate=0.05, noise_type='phase_flip')
```

### 退极化噪声

退极化噪声是更一般的噪声模型：

```python
model = noise_model(error_rate=0.05, noise_type='depolarizing')
```

## 噪声对 Bell 态的影响

```python
from quonic import qgate, qshow
from quonic.gates import H, CX

# 创建 Bell 态
qgate(H, 0)
qgate(CX, 0, 1)

# 无噪声
qshow(noise=0)

# 5% 噪声
qshow(noise=0.05)

# 20% 噪声
qshow(noise=0.20)
```

## 零噪声外推 (ZNE)

ZNE 是一种噪声缓解技术，通过外推到零噪声来提高结果精度。

```python
from quonic.mitigation import zne

# 在多个噪声水平下测量
noise_levels = [0.0, 0.01, 0.02, 0.03]
expectation_values = []

for noise in noise_levels:
    result = qshow(noise=noise)
    expectation_values.append(result.expectation)

# 外推到零噪声
mitigated = zne(noise_levels, expectation_values)
print(f"Mitigated value: {mitigated}")
```

## 量子纠错

量子纠错码可以检测和纠正量子错误：

```python
from quonic.qec import bit_flip_code

# 比特翻转码
result = bit_flip_code(error_qubit=1)
print(f"Corrected: {result.corrected}")
```
