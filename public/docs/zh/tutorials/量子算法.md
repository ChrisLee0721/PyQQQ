# 量子算法

学习基本的量子算法：Grover 搜索、Shor 算法、量子傅里叶变换等。

## Grover 搜索

Grover 搜索可以在无序数据库中快速找到目标，提供二次加速。

```python
from quonic.algorithms import grover

# 在 2-qubit 空间中搜索 |11>
result = grover("11", 2, shots=1024)
print(result.counts)
# 输出: {'11': 1008, '00': 6, '01': 5, '10': 5}
```

### 原理

1. 初始化：创建均匀叠加态
2. Oracle：标记目标态
3. Diffusion：放大目标态振幅
4. 重复 2-3 步，直到目标态概率足够高

## 量子傅里叶变换 (QFT)

QFT 是许多量子算法的基础，如 Shor 算法和量子相位估计。

```python
from quonic import qgate, qshow
from quonic.gates import H, Rz
import math

# 3-qubit QFT
qgate(H, 0)
qgate(Rz(math.pi/2), 1)
qgate(Rz(math.pi/4), 2)
qshow()
```

## 量子相位估计 (QPE)

QPE 用于估计酉算子的本征值，是 Shor 算法的核心。

```python
from quonic import qgate, qshow
from quonic.gates import H, X

# 简单的 QPE 示例
qgate(X, 1)  # 准备本征态
qgate(H, 0)  # 叠加态
qgate(CU, 0, 1)  # 受控 U 门
qshow()
```

## Shor 算法

Shor 算法可以在多项式时间内分解大整数，威胁 RSA 加密。

```python
from quonic.algorithms import shor

# 分解 N = 15
result = shor(15)
print(f"Factors: {result.factors}")
# 输出: Factors: [3, 5]
```

## VQE（变分量子本征求解器）

VQE 用于计算分子的基态能量，是量子化学的核心算法。

```python
from quonic.algorithms import vqe
from quonic.chemistry import molecule

# 计算 H2 分子的基态能量
mol = molecule("H2", bond_length=0.74)
result = vqe(mol, ansatz="uccsd", optimizer="cobyla")
print(f"Energy: {result.energy:.6f} Ha")
```

## QAOA（量子近似优化算法）

QAOA 用于解决组合优化问题，如 MaxCut。

```python
from quonic.algorithms import qaoa

# MaxCut 问题
graph = [(0,1), (1,2), (2,3), (3,0)]
result = qaoa(graph, p=2)
print(f"MaxCut: {result.maxcut_value}")
```
