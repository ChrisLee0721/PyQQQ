为什么需要？

Simon 算法是第一个证明量子指数加速的算法，是 Shor 算法的前身。

经典局限

  • 经典算法需要 \(O(2^{n/2})\) 次查询

  • 对于 \(n\) 量子比特，经典需要指数次查询

量子优势

  • Simon 算法只需要 \(O(n)\) 次查询

  • 提供指数加速

  • 是 Shor 算法的基础

实际应用

  • 量子算法设计

  • Shor 算法（大数分解）

  • 量子计算理论

快速上手

from quonic.algorithms import simon

# Find hidden period

预期输出：

原理详解

电路图

数学推导

Simon 算法寻找函数 \(f\) 的隐藏周期 \(s\)，使得 \(f(x) = f(x \oplus s)\)。

Step 1: 初始化 \[\begin{equation} |\psi_0\rangle = |0\rangle^{\otimes n}|0\rangle^{\otimes n} \end{equation}\]

Step 2: Hadamard 门 \[\begin{equation} |\psi_1\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle|0\rangle \end{equation}\]

Step 3: Oracle 查询 \[\begin{equation} |\psi_2\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle|f(x)\rangle \end{equation}\]

Step 4: 测量和后处理

测量第二个寄存器，得到 \(f(x)\)。对第一个寄存器施加 Hadamard 门，测量得到 \(y\)，使得 \(y \cdot s = 0 \mod 2\)。

通过多次运行，收集足够的方程，求解得到 \(s\)。

几何解释

Simon 算法利用量子叠加态同时查询所有输入，通过干涉效应提取隐藏的周期信息。

代码详解

from quonic.algorithms import simon

# simon(period, n_qubits)

print(f"Hidden period: {result.period}")

常见问题

Simon 算法的加速比是多少？

指数加速：经典需要 \(O(2^{n/2})\) 次查询，量子只需要 \(O(n)\) 次。

Simon 算法和 Shor 算法有什么关系？

Simon 算法是 Shor 算法的前身。Shor 算法将 Simon 算法推广到周期查找问题。

Simon 算法的局限性是什么？

Simon 算法只能处理二进制周期，不能处理一般的周期问题。
