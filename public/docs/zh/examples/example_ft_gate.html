QuoNic

Error Correction / 纠错 | 难度：高级 | 预计时间：20 分钟

为什么需要？

容错门是在量子纠错码上执行的逻辑门。

经典局限

  • 普通量子门会传播错误

  • 需要容错门避免错误传播

量子优势

  • 容错门可以避免错误传播

  • 是容错量子计算的基础

  • 提高量子计算的可靠性

实际应用

  • 容错量子计算

  • 量子纠错

  • 量子通信

快速上手

from quonic.qec import ft_gate

# 容错门
result = ft_gate(gate='H', code='steane')
print(f'Fault-tolerant circuit: {result.circuit}')

预期输出：

Fault-tolerant circuit: ...

原理详解

电路图

数学推导

容错门： \[\begin{equation} U_L = \text{transversal}(U) \end{equation}\]

其中 \(U\) 是逻辑门，\(U_L\) 是容错门。

几何解释

容错门在逻辑量子比特上执行操作，同时避免错误传播。

代码详解

from quonic.qec import ft_gate

# ft_gate(gate, code)
# gate: 逻辑门
# code: 纠错码

result = ft_gate(
    gate='H',
    code='steane'
)

# result.circuit: 容错电路
# result.depth: 电路深度
# result.gate_count: 门数量
print(f'Fault-tolerant circuit: {result.circuit}')

适用场景

容错量子计算

容错门是容错量子计算的基础。容错门可以避免错误传播，提高量子计算的可靠性。

量子纠错

容错门用于量子纠错码上的逻辑操作。例如，在 Steane 码上执行 Hadamard 门。

常见问题

容错门和普通门有什么区别？

容错门可以避免错误传播，普通门会传播错误。

容错门有哪些类型？

常见的容错门包括：横向门、魔术态蒸馏门等。
