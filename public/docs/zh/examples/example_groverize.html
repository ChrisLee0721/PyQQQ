为什么需要？

Groverize 是将任意 Oracle 自动转换为 Grover 搜索的工具。

经典局限

  • 手动构造 Grover 搜索电路复杂

  • 需要理解 Oracle 和 Diffusion 算子

  • 容易出错

量子优势

  • Groverize 自动构造 Grover 搜索电路

  • 只需要提供 Oracle

  • 自动计算最优迭代次数

实际应用

  • 数据库搜索

  • 组合优化

  • 密码学分析

快速上手

from quonic.algorithms import groverize

# 自动构造 Grover 搜索
oracle = lambda x: x == '11'
result = groverize(oracle, n_qubits=2)
print(f'Found: {result.found}')
print(f'Probability: {result.probability}')

预期输出：

Found: 11
Probability: 0.99

数学推导

Groverize 自动构造 Grover 搜索： \[\begin{equation} G = D \cdot O \end{equation}\]

其中 \(O\) 是 Oracle，\(D\) 是 Diffusion 算子。

最优迭代次数： \[\begin{equation} k \approx \frac{\pi}{4} \sqrt{N} \end{equation}\]

几何解释

Groverize 在 Bloch 球上旋转量子态，每次迭代放大目标态的振幅。

代码详解

from quonic.algorithms import groverize

# groverize(oracle, n_qubits, iterations)
# oracle: Oracle 函数
# n_qubits: 量子比特数
# iterations: 迭代次数（默认自动计算）

result = groverize(
    oracle=lambda x: x == '11',
    n_qubits=2,
    iterations='auto'
)

# result.found: 找到的目标态
# result.probability: 成功概率
# result.circuit: 量子电路
print(f'Found: {result.found}')

进阶用法

场景 1：不同 Oracle

from quonic.algorithms import groverize

# 不同 Oracle
oracle1 = lambda x: x == '101'  # 精确匹配
oracle2 = lambda x: x.count('1') > 1  # 条件匹配
oracle3 = lambda x: int(x, 2) > 5  # 数值比较

for oracle in [oracle1, oracle2, oracle3]:
    result = groverize(oracle, n_qubits=3)
    print(f'Found: {result.found}')

场景 2：多目标搜索

from quonic.algorithms import groverize

# 多目标搜索
oracle = lambda x: x in ['00', '11']
result = groverize(oracle, n_qubits=2)
print(f'Found: {result.found}')

适用场景

数据库搜索

Groverize 可以自动构造数据库搜索电路。只需要提供查询函数，Groverize 会自动构造 Grover 搜索。

组合优化

Groverize 可以用于组合优化问题。例如，寻找满足约束的最优解。

常见问题

Groverize 和 Grover 搜索有什么区别？

Groverize 是自动化的 Grover 搜索。只需要提供 Oracle，Groverize 会自动构造电路。

Groverize 的精度如何？

精度取决于迭代次数。自动计算的迭代次数通常能达到 99% 以上的成功概率。
