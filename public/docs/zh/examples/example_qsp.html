为什么需要？

量子信号处理是量子算法设计的通用框架，可以统一描述许多量子算法。

经典局限

  • 经典信号处理受限于有限的变换类型

  • 对于高维信号，经典方法效率低

量子优势

  • 量子信号处理可以实现任意多项式变换

  • 是许多量子算法的统一框架

  • 提供最优的查询复杂度

实际应用

  • 量子算法设计

  • 量子模拟

  • 量子优化

快速上手

from quonic.algorithms import qsp

# 量子信号处理
result = qsp(polynomial=[1, 0, -1], n_qubits=2)
print(f'Result: {result.output}')

预期输出：

Result: [0.5, 0.5]

原理详解

电路图

数学推导

量子信号处理： \[\begin{equation} U = e^{i\theta_0 Z} \prod_{k=1}^{d} W e^{i\theta_k Z} \end{equation}\]

其中 \(W\) 是信号算子，\(\theta_k\) 是相位角度。

几何解释

量子信号处理在 Bloch 球上旋转量子态，通过相位角度实现任意多项式变换。

代码详解

from quonic.algorithms import qsp

# qsp(polynomial, n_qubits)
# polynomial: 多项式系数
# n_qubits: 量子比特数
result = qsp(polynomial=[1, 0, -1], n_qubits=2)

# result.output: 输出态
# result.angles: 相位角度
print(f'Result: {result.output}')

适用场景

量子算法设计

量子信号处理是许多量子算法的统一框架，如 Grover 搜索、量子计数等。

量子模拟

量子信号处理可以用于模拟量子系统的时间演化。

常见问题

量子信号处理和 QSP 有什么区别？

QSP 是 Quantum Signal Processing 的缩写，两者是同一个概念。

量子信号处理的精度如何？

精度取决于多项式的阶数。更高的阶数提供更高的精度。
