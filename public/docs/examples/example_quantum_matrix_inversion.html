为什么需要？

量子矩阵求逆是 HHL 算法的核心组件，用于求解线性方程组。

经典局限

̱

  • 经典矩阵求逆需要 \(O(N^3)\) 时间

  • 对于大规模矩阵，经典方法效率低

量子优势

̱

  • 量子矩阵求逆需要 \(O(\text{poly}(\log N))\) 时间

  • 对于稀疏矩阵，提供指数加速

  • 是量子机器学习的基础

实际应用

̱

  • 线性方程组求解

  • 量子机器学习

  • 量子模拟

快速上手

from quonic.algorithms import quantum_matrix_inversion

# Invert a matrix
A = [[1, 0], [0, 2]]
result = quantum_matrix_inversion(A)
print(f"Inverse: {result.inverse}")

预期输出：

Inverse: [[1.0, 0.0], [0.0, 0.5]]

原理详解

电路图

数学推导

量子矩阵求逆估计 \(A^{-1}\)： \[\begin{equation} A^{-1} = \sum_i \frac{1}{\lambda_i} |v_i\rangle\langle v_i| \end{equation}\]

算法步骤：

  1. 用 QPE 估计 \(A\) 的本征值 \(\lambda_i\)

  2. 用受控旋转将本征值取倒数 \(1/\lambda_i\)

  3. 用逆 QPE 恢复量子态

几何解释

量子矩阵求逆在量子态空间中操作，通过 QPE 将矩阵对角化，然后取倒数得到逆矩阵。

常见问题

量子矩阵求逆的加速比是多少？

指数加速：\(O(\text{poly}(\log N))\) vs \(O(N^3)\)。

量子矩阵求逆的局限性是什么？

需要矩阵是稀疏的，且条件数不能太大。
