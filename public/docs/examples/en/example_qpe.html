Why do we need it?

Quantum Phase Estimation (QPE) is the core of many quantum algorithms, used to estimate eigenvalues of unitary operators.

Classical Limitations

  • Classical methods cannot efficiently estimate quantum state phases

  • For large quantum systems, classical methods require exponential time

Quantum Advantages

  • QPE can efficiently estimate eigenvalues of unitary operators

  • Core of Shor’s algorithm, quantum chemistry simulation

  • Provides exponential speedup

Real-world Applications

  • Shor’s Algorithm (factoring)

  • Quantum Chemistry (molecular energy calculation)

  • Quantum Machine Learning (kernel methods)

Quick Start

from quonic import qgate, qshow
from quonic.gates import H, X

# Simple QPE example
qgate(X, 1)  # Prepare eigenstate
qgate(H, 0)  # Superposition
qgate(CU, 0, 1)  # Controlled-U
qshow()

Mathematical Derivation

QPE estimates eigenvalue \(e^{2\pi i\theta}\) of unitary operator \(U\): \[\begin{equation} U|\psi\rangle = e^{2\pi i\theta}|\psi\rangle \end{equation}\]

QPE outputs \(n\)-bit approximation of \(\theta\): \[\begin{equation} |0\rangle^{\otimes n}|\psi\rangle \xrightarrow{QPE} |\tilde{\theta}\rangle|\psi\rangle \end{equation}\]

Where \(\tilde{\theta} \approx \theta\), with precision \(n\) bits.

Geometric Interpretation

QPE encodes phase information into control qubits on the Bloch sphere. Through inverse QFT, phase information is converted to measurable computational basis states.

Advanced Usage

Scenario 1: Multi-bit QPE

# Multi-bit QPE for higher precision
n = 3  # 3 control qubits
qgate(X, n)  # Prepare eigenstate
for i in range(n):
    qgate(H, i)
    qgate(CU, i, n)
qshow()

Scenario 2: QPE for Molecular Simulation

# QPE for molecular simulation
# Estimate ground state energy
qgate(X, 3)  # Prepare molecular state
qgate(H, 0)
qgate(H, 1)
qgate(H, 2)
qgate(CU, 0, 3)
qgate(CU, 1, 3)
qgate(CU, 2, 3)
qshow()

Use Cases

Quantum Chemistry

Quantum Machine Learning

QPE is used in quantum kernel methods for eigenvalue estimation.

FAQ

What is the precision of QPE?

Precision is determined by the number of control qubits \(n\). More qubits = higher precision.

How many qubits does QPE need?

QPE needs \(n\) control qubits + 1 target qubit.

What is the output of QPE?

QPE output is a binary approximation of phase \(\theta\).
