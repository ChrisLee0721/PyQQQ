Why do we need it?

GHZ state is a multi-qubit generalization of Bell state, another important form of quantum entanglement.

Classical Limitations

  • Classical physics cannot create perfect correlations of three or more particles

  • Classical communication cannot implement multi-party quantum protocols

Quantum Advantages

  • GHZ state is the foundation for quantum error correction

  • Used in multi-party quantum communication and quantum secret sharing

  • Common entangled state in quantum computing

Real-world Applications

  • Quantum Error Correction (surface codes, color codes)

  • Quantum Secret Sharing (multi-party protocols)

  • Quantum Computing Testing (multi-qubit entanglement verification)

Quick Start

from quonic import qgate, qshow
from quonic.gates import CX, H

# Create GHZ state: (|000>+|111>)/sqrt(2)
qgate(H, 0)
qgate(CX, 0, 1)
qgate(CX, 1, 2)
qshow()

Theory Deep Dive

Circuit Diagram

Mathematical Derivation

Step 1: Initial State

Three qubits start from \(|0\rangle\): \[\begin{equation} |\psi_0\rangle = |000\rangle \end{equation}\]

Step 2: Hadamard Gate

Apply \(H\) gate to \(q_0\): \[\begin{equation} |\psi_1\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}} \otimes |00\rangle = \frac{|000\rangle + |100\rangle}{\sqrt{2}} \end{equation}\]

Step 3: CNOT Chain

CNOT\((q_0, q_1)\) and CNOT\((q_1, q_2)\) create three-qubit entanglement: \[\begin{equation} |\psi_2\rangle = \frac{|000\rangle + |111\rangle}{\sqrt{2}} \end{equation}\]

Step 4: Measurement Probabilities

  • \(P(|000\rangle) = 0.5\)

  • \(P(|111\rangle) = 0.5\)

  • All other states have probability 0

Geometric Interpretation

GHZ state is a maximally entangled state of three qubits. On the Bloch sphere, the three qubits are fully correlated — measuring one instantly determines the other two.

Advanced Usage

Scenario 1: N-qubit GHZ State

# N-qubit GHZ state
n = 5
qgate(H, 0)

    qgate(CX, i, i + 1)

# GHZ state for error correction
# Encode logical qubit in GHZ state
qgate(H, 0)

# Syndrome measurement
qgate(CX, 0, 3)

Use Cases

Quantum Error Correction

GHZ state is the foundation for quantum error correction codes. Surface codes and color codes use multi-qubit entanglement to protect quantum information.

Quantum Secret Sharing

In quantum secret sharing protocols, GHZ state is used to distribute secrets to multiple parties. Only all parties together can recover the secret.

Quantum Computing Testing

GHZ state is the standard benchmark for testing multi-qubit entanglement capabilities of quantum hardware.

FAQ

What’s the difference between GHZ state and Bell state?

Bell state is 2-qubit entanglement, GHZ state is 3+ qubit entanglement. GHZ state is a generalization of Bell state.

Why does GHZ state only have |000> and |111>?

Because the CNOT chain propagates the state of \(q_0\) to all qubits. If \(q_0\) is \(|0\rangle\), all qubits are \(|0\rangle\); if \(q_0\) is \(|1\rangle\), all qubits are \(|1\rangle\).

What are the entanglement properties of GHZ state?

GHZ state is a maximally entangled state — measuring one qubit instantly determines all other qubits.
