Algorithms / 算法 | 难度：高级 | 预计时间：20 分钟

为什么需要？

振幅估计用于估计量子算法的成功概率。

经典局限

  • 经典方法需要多次采样才能估计概率

  • 对于小概率事件，经典方法效率低

量子优势

  • 振幅估计只需要 \(O(1/\epsilon)\) 次查询

  • 提供二次加速

  • 是量子算法分析的基础

实际应用

  • 量子算法分析

  • 量子优化

  • 量子机器学习

快速上手

from quonic.algorithms import amplitude_estimation
result = amplitude_estimation(target='11', n_qubits=2)
print(f'Estimate: {result.estimate}')

预期输出：

Estimate: 0.5

原理详解

电路图

数学推导

振幅估计结合了振幅放大和量子相位估计： \[\begin{equation} \theta = \arcsin(\sqrt{p}) \end{equation}\]

其中 \(p\) 是目标态的概率。

算法步骤：

  1. 用振幅放大旋转相位

  2. 用 QPE 估计相位 \(\theta\)

  3. 计算概率 \(p = \sin^2(\theta)\)

几何解释

振幅估计在 Bloch 球上估计旋转角度，从而推算成功概率。

代码详解

from quonic.algorithms import amplitude_estimation

# amplitude_estimation(target, n_qubits, precision)
# target: target bit string
# n_qubits: number of qubits
# precision: number of precision qubits
result = amplitude_estimation(target='11', n_qubits=2)

# result.estimate: estimated probability
# result.phase: estimated phase
print(f'Estimate: {result.estimate}')

常见问题

振幅估计和振幅放大有什么区别？

振幅估计估计概率，振幅放大放大概率。

振幅估计的精度如何？

精度取决于控制量子比特的数量。更多的控制量子比特提供更高的精度。
