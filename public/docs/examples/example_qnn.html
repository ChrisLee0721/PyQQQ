为什么需要？

量子神经网络是经典神经网络的量子推广，利用量子叠加和纠缠处理高维数据。

经典局限

  • 经典神经网络训练慢，对于高维数据需要大量参数

  • 经典网络受限于有限的激活函数类型

  • 对于某些问题，经典网络容易陷入局部最优

量子优势

  • 量子神经网络可以表示任意函数（通用逼近定理）

  • 量子网络可以利用量子叠加探索更大的参数空间

  • 对于某些问题，量子网络提供指数加速

实际应用

  • 分类问题（如图像分类、文本分类）

  • 回归问题（如函数拟合、时间序列预测）

  • 强化学习（如游戏 AI、机器人控制）

  • 生成模型（如图像生成、数据增强）

原理详解

电路图

数学推导

Step 1: 量子态编码

将经典数据 \(x\) 编码为量子态： \[\begin{equation} |x\rangle = U_{\text{enc}}(x)|0\rangle^{\otimes n} \end{equation}\]

其中 \(U_{\text{enc}}\) 是编码电路。

Step 2: 参数化量子电路

应用参数化量子电路： \[\begin{equation} |\psi(\theta)\rangle = U_L(\theta_L) \cdots U_2(\theta_2) U_1(\theta_1)|x\rangle \end{equation}\]

其中 \(U_l(\theta_l)\) 是第 \(l\) 层的参数化门。

Step 3: 测量

测量量子态得到输出： \[\begin{equation} f(x) = \langle\psi(\theta)|M|\psi(\theta)\rangle \end{equation}\]

其中 \(M\) 是测量算子。

Step 4: 损失函数

定义损失函数： \[\begin{equation} L(\theta) = \frac{1}{N} \sum_i (f(x_i) - y_i)^2 \end{equation}\]

Step 5: 参数更新

使用梯度下降更新参数： \[\begin{equation} \theta_{t+1} = \theta_t - \eta \nabla L(\theta_t) \end{equation}\]

其中 \(\eta\) 是学习率。

几何解释

量子神经网络在 Bloch 球上操作量子态。每一层参数化门旋转量子态，最终测量得到输出。

量子神经网络的参数空间是连续的，可以使用梯度下降优化。量子叠加允许网络同时探索多个参数路径。

代码详解

from quonic.ml import qnn

# qnn(data, labels, n_layers, learning_rate, epochs)
# data: 训练数据，形状为 (n_samples, n_features)
# labels: 标签，形状为 (n_samples,)
# n_layers: 量子电路层数
# learning_rate: 学习率
# epochs: 训练轮数

result = qnn(
    data=[[0, 1], [1, 0], [1, 1], [0, 0]],
    labels=[0, 1, 1, 0],
    n_layers=2,
    learning_rate=0.01,
    epochs=100
)

# result.accuracy: 准确率
# result.loss: 损失值
# result.params: 优化后的参数
# result.history: 训练历史
print(f'Accuracy: {result.accuracy}')
print(f'Loss: {result.loss}')

进阶用法

场景 1：量子特征映射与数据编码

不同的数据编码方式会影响 QNN 的表达能力：

from quonic.ml import qnn
import math

# 方式 1：角度编码（将数据编码为旋转角度）
# 适用于：特征值在 [0, 2pi] 范围内
data_angle = [[math.pi/4, math.pi/2], [math.pi, 3*math.pi/4]]

# 方式 2：振幅编码（将数据编码为量子态振幅）
# 适用于：高维数据，需要 log2(n) 个量子比特
data_amplitude = [[0.6, 0.8], [0.8, 0.6]]  # 需要归一化

# 方式 3：基编码（将二进制数据编码为计算基态）
# 适用于：二进制特征
data_basis = [[0, 1], [1, 0], [1, 1], [0, 0]]

# 比较不同编码方式的效果
for name, data in [("Angle", data_angle), ("Amplitude", data_amplitude), ("Basis", data_basis)]:
    result = qnn(data, [0, 1], n_layers=2)
    print(f'{name} encoding: Accuracy={result.accuracy}')

场景 2：量子神经网络的表达能力分析

QNN 的表达能力取决于电路深度和参数数量：

from quonic.ml import qnn
import numpy as np

# 生成复杂数据集（非线性可分）
np.random.seed(42)
X = np.random.randn(50, 2)
y = ((X[:, 0]**2 + X[:, 1]**2) > 1).astype(int).tolist()

# 测试不同深度的表达能力
results = []
for depth in [1, 2, 3, 4, 5]:
    result = qnn(X.tolist(), y, n_layers=depth, n_epochs=200)
    results.append((depth, result.accuracy, result.loss))
    print(f'Depth {depth}: Accuracy={result.accuracy:.3f}, Loss={result.loss:.3f}')

# 分析：深度增加 → 表达能力增强 → 但可能过拟合
# 最佳深度取决于数据复杂度和噪声水平

场景 3：量子梯度下降与参数优化

QNN 使用参数平移规则计算梯度：

from quonic.ml import qnn

# 自定义优化器和学习率调度
result = qnn(
    data=[[0, 1], [1, 0], [1, 1], [0, 0]],
    labels=[0, 1, 1, 0],
    n_layers=2,
    optimizer='parameter_shift',  # 量子梯度下降
    learning_rate=0.1,
    lr_schedule='cosine',  # 余弦退火
    n_epochs=200
)

# 分析训练过程
import matplotlib.pyplot as plt
plt.plot(result.history['loss'])
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('QNN Training Loss')
plt.savefig('qnn_training.png')

# 量子梯度下降的收敛性：
# - 参数平移规则：精确计算梯度，无需经典近似
# - 学习率调度：避免陷入局部最优
# - 早停策略：防止过拟合

量子神经网络可以用于预测药物分子的溶解度、毒性等性质。QNN 可以利用量子特征映射在高维空间中学习分子结构与性质的复杂关系。

金融时间序列预测

量子神经网络可以用于股票价格、汇率等时间序列预测。QNN 可以利用量子叠加和纠缠捕捉金融数据中的非线性模式。

材料性质预测

量子神经网络可以用于预测材料的电子结构、力学性质。QNN 可以自然地表示量子效应，比经典神经网络更高效。

小样本学习

量子神经网络在小样本场景下可能有优势。量子特征映射可以将数据映射到高维空间，使得小样本数据变得线性可分。

常见问题

量子神经网络的表达能力如何？

量子神经网络是通用逼近器，可以表示任意函数。对于 \(n\) 个量子比特，可以表示 \(2^n\) 维空间中的任意函数。

量子神经网络需要多少量子比特？

量子神经网络需要的量子比特数取决于特征维度。对于 \(d\) 维特征，需要 \(\lceil \log_2(d) \rceil\) 个量子比特。

量子神经网络的训练时间如何？

量子神经网络的训练时间包括：

  • 前向传播：\(O(T_{\text{circuit}})\)

  • 梯度计算：\(O(T_{\text{circuit}})\)

  • 参数更新：\(O(1)\)

其中 \(T_{\text{circuit}}\) 是量子电路的执行时间。

量子神经网络和经典神经网络有什么区别？

量子神经网络使用量子门作为激活函数，可以在更高维的空间中表示函数。经典神经网络使用经典激活函数（如 ReLU、Sigmoid），受限于有限的函数类型。

量子神经网络的收敛性如何？

量子神经网络的收敛性取决于：

  • 学习率的选择

  • 量子电路的深度

  • 数据的质量
