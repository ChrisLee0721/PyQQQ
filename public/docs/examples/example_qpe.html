为什么需要？

量子相位估计（QPE）是许多量子算法的核心，用于估计酉算子的本征值。

经典局限

  • 经典方法无法高效估计量子态的相位

  • 对于大规模量子系统，经典方法需要指数时间

量子优势

  • QPE 可以高效估计酉算子的本征值

  • 是 Shor 算法、量子化学模拟的核心

  • 提供指数加速

实际应用

  • Shor 算法（大数分解）

  • 量子化学（分子能量计算）

  • 量子机器学习（核方法）

快速上手

from quonic import qgate, qshow
from quonic.gates import H, X

# Simple QPE example
qgate(X, 1)  # Prepare eigenstate
qgate(H, 0)  # Superposition
qgate(CU, 0, 1)  # Controlled-U
qshow()

原理详解

电路图

数学推导

QPE 估计酉算子 \(U\) 的本征值 \(e^{2\pi i\theta}\)： \[\begin{equation} U|\psi\rangle = e^{2\pi i\theta}|\psi\rangle \end{equation}\]

QPE 输出 \(\theta\) 的 \(n\) 位近似： \[\begin{equation} |0\rangle^{\otimes n}|\psi\rangle \xrightarrow{QPE} |\tilde{\theta}\rangle|\psi\rangle \end{equation}\]

其中 \(\tilde{\theta} \approx \theta\)，精度为 \(n\) 位。

几何解释

QPE 在 Bloch 球上将相位信息编码到控制量子比特中。通过 QFT 逆变换，将相位信息转换为可测量的计算基态。

代码详解

from quonic import qgate, qshow
from quonic.gates import H, X

# Prepare eigenstate |1>
qgate(X, 1)

# Create superposition
qgate(H, 0)

# Apply controlled-U
qgate(CU, 0, 1)

# Measure
qshow()

进阶用法

场景 1：多比特 QPE

# Multi-bit QPE for higher precision
n = 3  # 3 control qubits
qgate(X, n)  # Prepare eigenstate
for i in range(n):
    qgate(H, i)
    qgate(CU, i, n)
qshow()

场景 2：QPE 用于分子模拟

# QPE for molecular simulation
# Estimate ground state energy
qgate(X, 3)  # Prepare molecular state
qgate(H, 0)
qgate(H, 1)
qgate(H, 2)
qgate(CU, 0, 3)
qgate(CU, 1, 3)
qgate(CU, 2, 3)
qshow()

量子机器学习

常见问题

QPE 的精度是多少？

QPE 的精度由控制量子比特数 \(n\) 决定。\(n\) 越大，精度越高。

QPE 需要多少量子比特？

QPE 需要 \(n\) 个控制量子比特 + 1 个目标量子比特。

QPE 的输出是什么？

QPE 的输出是相位 \(\theta\) 的二进制近似。
