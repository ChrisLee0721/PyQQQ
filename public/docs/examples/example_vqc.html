为什么需要？

变分量子分类器是经典分类器的量子推广，用于在量子环境中进行分类。

经典局限

  • 经典分类器在高维数据上训练慢

  • 对于复杂数据，经典方法效率低

量子优势

  • 变分量子分类器可以利用量子特征映射在高维空间中分类

  • 训练速度更快

  • 可以处理更复杂的数据

实际应用

  • 图像分类

  • 文本分类

  • 异常检测

快速上手

from quonic.ml import vqc

labels = [0, 1, 1, 0]

原理详解

电路图

数学推导

变分量子分类器： \[\begin{equation} f(x) = \langle 0|U^\dagger(\theta) M U(\theta)|0\rangle \end{equation}\]

其中 \(U(\theta)\) 是参数化量子电路，\(M\) 是测量算子。

损失函数： \[\begin{equation} L(\theta) = \frac{1}{N} \sum_i (f(x_i) - y_i)^2 \end{equation}\]

梯度下降： \[\begin{equation} \theta_{t+1} = \theta_t - \eta \nabla L(\theta_t) \end{equation}\]

几何解释

变分量子分类器在量子态空间中学习分类边界。量子特征映射将数据映射到高维空间，使得线性不可分的数据变得线性可分。

代码详解

from quonic.ml import vqc

# vqc(data, labels, n_layers, learning_rate)
# data: 训练数据
# labels: 标签
# n_layers: 量子电路层数
# learning_rate: 学习率

result = vqc(
    data=[[0, 1], [1, 0], [1, 1], [0, 0]],
    labels=[0, 1, 1, 0],
    n_layers=2,
    learning_rate=0.01
)

# result.accuracy: 准确率
# result.loss: 损失值
# result.params: 优化后的参数
print(f'Accuracy: {result.accuracy}')

进阶用法

场景 1：不同层数

from quonic.ml import vqc

data = [[0, 1], [1, 0], [1, 1], [0, 0]]
labels = [0, 1, 1, 0]

for n in [1, 2, 3]:
    result = vqc(data, labels, n_layers=n)
    print(f'n={n}: Accuracy={result.accuracy}')

场景 2：不同数据集

from quonic.ml import vqc
import numpy as np

# 不同数据集
X = np.random.randn(20, 2)
y = (X[:, 0]**2 + X[:, 1]**2 > 1).astype(int).tolist()

result = vqc(X.tolist(), y, n_layers=3)
print(f'Accuracy: {result.accuracy}')

场景 3：多分类

常见问题

变分量子分类器和经典分类器有什么区别？

变分量子分类器使用量子特征映射，可以在更高维的空间中分类。

变分量子分类器的精度如何？

精度取决于量子电路的深度和数据的质量。
