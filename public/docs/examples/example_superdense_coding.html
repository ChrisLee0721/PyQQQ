Why do we need it?

Superdense coding uses 1 qubit to transmit 2 classical bits, an important quantum communication protocol.

Classical Limitations

  • Classical communication: 1 qubit can only transmit 1 classical bit

  • Classical communication needs 2 channels to transmit 2 bits

Quantum Advantages

  • Superdense coding: 1 qubit transmits 2 classical bits

  • Uses entanglement for information compression

  • Foundation for quantum communication

Real-world Applications

  • Quantum Communication (efficient information transfer)

  • Quantum Networks (quantum internet)

  • Quantum Cryptography (quantum key distribution)

Mathematical Derivation

Superdense coding protocol:

  1. Alice and Bob share Bell pair \(|\Phi^+\rangle = (|00\rangle + |11\rangle)/\sqrt{2}\)

  2. Alice encodes 2-bit message:

    • 00: no operation

    • 01: apply \(X\) gate

    • 10: apply \(Z\) gate

    • 11: apply \(ZX\) gate

  3. Alice sends her qubit to Bob

  4. Bob decodes to get 2-bit message

Geometric Interpretation

Superdense coding uses entanglement as a quantum channel. Alice’s operations change the entanglement structure of the Bell pair, and Bob decodes to recover information.

FAQ

Why can superdense coding transmit 2 bits?

Superdense coding uses entanglement as a quantum channel. Alice’s operations change the Bell pair’s entanglement structure, and Bob decodes to recover 2 bits of information.

What’s the difference between superdense coding and teleportation?

Superdense coding: 1 qubit transmits 2 classical bits. Teleportation: 2 classical bits transmit 1 qubit.

How many qubits does superdense coding need?

Superdense coding needs 2 qubits: 1 for Alice, 1 for Bob (shared Bell pair).
