Simulation / 模拟 | 难度：高级 | 预计时间：20 分钟

为什么需要？

量子动力学模拟用于模拟量子系统的时间演化。

经典局限

  • 经典模拟需要指数时间，对于 \(n\) 个量子比特需要 \(O(2^n)\) 内存

  • 对于大系统，经典方法效率低

  • 精确对角化只适用于小系统

量子优势

  • 量子模拟可以在多项式时间内完成

  • 提供指数加速

  • 是量子化学的基础

实际应用

  • 量子化学（分子动力学模拟）

  • 材料科学（新材料设计）

  • 量子物理（量子多体系统）

快速上手

from quonic.simulation import dynamics

# 模拟量子动力学
result = dynamics(H=[[1,0],[0,-1]], t=1.0, dt=0.1)
print(f'Final state: {result.state}')
print(f'Evolution: {result.evolution}')

预期输出：

Final state: [0.54+0.84j, 0]
Evolution: [[0.54+0.84j, 0], [0, 0.54-0.84j]]

原理详解

电路图

数学推导

Step 1: 薛定谔方程

量子系统的时间演化由薛定谔方程描述： \[\begin{equation} i\hbar \frac{d}{dt}|\psi(t)\rangle = H|\psi(t)\rangle \end{equation}\]

Step 2: 形式解

形式解： \[\begin{equation} |\psi(t)\rangle = e^{-iHt/\hbar}|\psi(0)\rangle \end{equation}\]

Step 3: Trotter 分解

对于大系统，使用 Trotter 分解： \[\begin{equation} e^{-iHt} \approx \prod_k e^{-iH_k \Delta t} \end{equation}\]

Step 4: 量子电路实现

每个 \(e^{-iH_k \Delta t}\) 可以用量子门实现： \[\begin{equation} e^{-iH_k \Delta t} = U_k e^{-i\lambda_k \Delta t} U_k^\dagger \end{equation}\]

Step 5: 测量

测量量子态得到物理量： \[\begin{equation} \langle A \rangle = \langle\psi(t)|A|\psi(t)\rangle \end{equation}\]

几何解释

量子动力学在 Bloch 球上演化量子态。哈密顿量决定旋转轴，时间决定旋转角度。

代码详解

from quonic.simulation import dynamics

# dynamics(H, t, dt, initial_state)
# H: 哈密顿量矩阵
# t: 总时间
# dt: 时间步长
# initial_state: 初始态

result = dynamics(
    H=[[1, 0], [0, -1]],
    t=1.0,
    dt=0.1,
    initial_state=[1, 0]
)

# result.state: 最终态
# result.evolution: 演化算子
# result.energies: 能量本征值
# result.expectation: 期望值
print(f'Final state: {result.state}')
print(f'Evolution: {result.evolution}')

进阶用法

场景 1：自旋链动力学

模拟自旋链的时间演化：

from quonic.simulation import dynamics
import numpy as np

# 4-qubit 自旋链哈密顿量
# H = J * sum(Z_i * Z_{i+1}) + h * sum(X_i)
J = 1.0
h = 0.5
n = 4

# 构造哈密顿量
H = np.zeros((2**n, 2**n))

# Z_i Z_{i+1} 耦合项
for i in range(n-1):
    for j in range(2**n):
        # 计算 Z_i Z_{i+1} 的本征值
        bit_i = (j >> (n-1-i)) & 1
        bit_i1 = (j >> (n-2-i)) & 1
        H[j, j] += J * ((-1)**bit_i) * ((-1)**bit_i1)

# X_i 横场项
for i in range(n):
    for j in range(2**n):
        # X_i 翻转第 i 个比特
        j_flipped = j ^ (1 << (n-1-i))
        H[j, j_flipped] += h

# 初始态：所有自旋向上 |0000>
psi0 = np.zeros(2**n)
psi0[0] = 1.0

# 模拟动力学
result = dynamics(H.tolist(), t=2.0, dt=0.1, initial_state=psi0.tolist())

# 计算磁化强度
M_z = np.zeros((2**n, 2**n))
for j in range(2**n):
    M_z[j, j] = sum(1 - 2*((j >> k) & 1) for k in range(n))

magnetization = np.real(psi0.conj() @ result.evolution @ M_z @ result.evolution.conj().T @ psi0)
print(f'Final magnetization: {magnetization:.4f}')

场景 2：量子退相干模拟

模拟开放量子系统的退相干：

from quonic.simulation import dynamics
from quonic.noise import noise_model
import numpy as np

# 二能级系统（量子比特）
H = [[1, 0], [0, -1]]  # 自旋-z 哈密顿量

# 纯态演化
result_pure = dynamics(H, t=1.0, dt=0.01)
print(f'Pure state evolution: {result_pure.state}')

# 加入退相干噪声
# T1 过程：能量弛豫
# T2 过程：相位弛豫
for T1, T2 in [(1.0, 0.5), (0.5, 0.2), (0.2, 0.1)]:
    noise = noise_model(
        error_rate=0.01,
        noise_type='decoherence',
        T1=T1,
        T2=T2
    )

    result_noisy = dynamics(H, t=1.0, dt=0.01, noise_model=noise)

    # 计算纯度
    rho = np.outer(result_noisy.state, np.conj(result_noisy.state))
    purity = np.real(np.trace(rho @ rho))

    print(f'T1={T1}, T2={T2}: Purity={purity:.4f}')

# 分析：T2 < T1 时，相位弛豫比能量弛豫更快
# 这导致量子叠加态快速退相干

场景 3：量子相变模拟

模拟量子相变点附近的动力学：

from quonic.simulation import dynamics
import numpy as np

# 横场 Ising 模型
# H = -J * sum(Z_i * Z_{i+1}) - h * sum(X_i)
# 当 h/J = 1 时发生量子相变

J = 1.0
n = 4

# 不同横场强度
h_values = [0.1, 0.5, 1.0, 2.0, 5.0]

for h in h_values:
    # 构造哈密顿量
    H = np.zeros((2**n, 2**n))

    # Z_i Z_{i+1} 项
    for i in range(n-1):
        for j in range(2**n):
            bit_i = (j >> (n-1-i)) & 1
            bit_i1 = (j >> (n-2-i)) & 1
            H[j, j] -= J * ((-1)**bit_i) * ((-1)**bit_i1)

    # X_i 项
    for i in range(n):
        for j in range(2**n):
            j_flipped = j ^ (1 << (n-1-i))
            H[j, j_flipped] -= h

    # 基态能量
    eigenvalues = np.linalg.eigvalsh(H)
    E0 = eigenvalues[0]
    E1 = eigenvalues[1]
    gap = E1 - E0

    print(f'h/J={h/J:.1f}: E0={E0:.4f}, Gap={gap:.4f}')

# 分析：在相变点 h/J=1，能隙最小
# 这是量子临界现象的特征

适用场景

化学反应动力学

动力学模拟可以模拟分子键的断裂和形成、反应速率常数等。传统方法使用经典近似，量子动力学模拟可以精确处理量子隧穿等量子效应。

光合作用机制

动力学模拟可以研究光合作用中的量子相干效应。光合作用的能量传输效率接近 100%，可能涉及量子效应。

量子退相干研究

动力学模拟可以精确模拟量子退相干过程。理解退相干机制有助于设计更好的量子纠错方案。

量子相变动力学

动力学模拟可以研究量子相变点附近的临界行为。这对于理解高温超导、量子磁性等现象非常重要。

量子物理

动力学模拟可以用于模拟量子多体系统。

常见问题

动力学模拟的精度如何？

取决于 Trotter 分解的阶数和时间步长。

动力学模拟需要多少量子比特？

取决于系统的大小。

动力学模拟和哈密顿量模拟有什么区别？

动力学模拟关注态演化，哈密顿量模拟关注演化算子。
