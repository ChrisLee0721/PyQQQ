为什么需要？

量子整数是量子程序中的整数数据类型。

经典局限

  • 经典整数无法直接用于量子态

  • 需要量子编码

量子优势

  • 量子整数可以在量子程序中使用整数操作

  • 是量子数据类型的基础

  • 支持量子算术运算

实际应用

  • 量子算术

  • 量子编码

  • 量子算法设计

快速上手

from quonic import qint

# 量子整数
a = qint(3, n_bits=4)
b = qint(5, n_bits=4)
c = a + b
print(f'Result: {c}')

预期输出：

Result: 8

原理详解

电路图

数学推导

量子整数编码： \[\begin{equation} |n\rangle = |b_{k-1} b_{k-2} \ldots b_1 b_0\rangle \end{equation}\]

其中 \(b_i\) 是二进制位。

量子加法： \[\begin{equation} |a\rangle|b\rangle \to |a\rangle|a+b\rangle \end{equation}\]

几何解释

量子整数在计算基态中编码整数值。量子算术运算通过量子门实现。

代码详解

from quonic import qint

# qint(value, n_bits)
# value: 整数值
# n_bits: 量子比特数

a = qint(3, n_bits=4)  # |0011>
b = qint(5, n_bits=4)  # |0101>

# 量子加法
c = a + b
print(f'Result: {c}')  # 8

适用场景

量子算术

量子整数用于量子算术运算。例如，量子加法、量子乘法等。

量子编码

量子整数用于量子编码。例如，将经典数据编码为量子态。

常见问题

量子整数和经典整数有什么区别？

量子整数在量子态中编码，经典整数在经典变量中存储。量子整数可以处于叠加态。

量子整数的精度如何？

精度取决于量子比特数。更多的量子比特提供更高的精度。
