为什么需要？

量子自然梯度是经典自然梯度的量子推广，用于优化量子电路参数。

经典局限

  • 经典梯度下降在参数空间中收敛慢

  • 对于量子电路，经典梯度下降效率低

量子优势

  • 量子自然梯度考虑了参数空间的几何结构

  • 收敛速度更快

  • 可以避免局部最优

实际应用

  • 量子电路优化

  • 量子机器学习

  • 量子化学

原理详解

电路图

数学推导

量子自然梯度： \[\begin{equation} \theta_{t+1} = \theta_t - \eta F^{-1} \nabla L(\theta_t) \end{equation}\]

其中 \(F\) 是 Fisher 信息矩阵。

Fisher 信息矩阵： \[\begin{equation} F_{ij} = \text{Re}\left(\langle\partial_i\psi|\partial_j\psi\rangle - \langle\partial_i\psi|\psi\rangle\langle\psi|\partial_j\psi\rangle\right) \end{equation}\]

几何解释

量子自然梯度考虑了参数空间的几何结构。Fisher 信息矩阵定义了参数空间的度量，自然梯度沿着最速下降方向。

代码详解

from quonic.ml import qng

# qng(data, labels, n_layers, learning_rate)
# data: 训练数据
# labels: 标签
# n_layers: 量子电路层数
# learning_rate: 学习率

result = qng(
    data=[[0, 1], [1, 0]],
    labels=[0, 1],
    n_layers=2,
    learning_rate=0.01
)

# result.loss: 损失值
# result.params: 优化后的参数
# result.fisher: Fisher 信息矩阵
print(f'Loss: {result.loss}')

进阶用法

场景 1：不同学习率

from quonic.ml import qng

data = [[0, 1], [1, 0]]

for lr in [0.001, 0.01, 0.1]:
    result = qng(data, labels, learning_rate=lr)
    print(f'lr={lr}: Loss={result.loss}')

场景 2：不同数据集

from quonic.ml import qng
import numpy as np

# 不同数据集
X = np.random.randn(20, 2)
y = (X[:, 0]**2 + X[:, 1]**2 > 1).astype(int).tolist()

result = qng(X.tolist(), y, n_layers=3)
print(f'Loss: {result.loss}')

场景 3：与普通梯度下降比较

from quonic.ml import qng, qnn

data = [[0, 1], [1, 0], [1, 1], [0, 0]]
labels = [0, 1, 1, 0]

# 普通梯度下降
result_gd = qnn(data, labels, n_layers=2, optimizer='gradient_descent')
print(f'Gradient descent: Loss={result_gd.loss}')

# 量子自然梯度
result_qng = qng(data, labels, n_layers=2)
print(f'QNG: Loss={result_qng.loss}')

# QNG 通常收敛更快

常见问题

量子自然梯度和经典梯度下降有什么区别？

量子自然梯度考虑了参数空间的几何结构，经典梯度下降没有。

量子自然梯度的收敛性如何？

量子自然梯度的收敛性取决于学习率和 Fisher 信息矩阵的条件数。
