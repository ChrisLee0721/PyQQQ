为什么需要？

基本量子门是量子计算的基础构建块。

经典局限

  • 经典逻辑门（AND、OR、NOT）是不可逆的

  • 经典门无法创建叠加态

  • 经典门无法创建纠缠态

量子优势

  • 量子门是可逆的

  • 可以创建叠加态和纠缠态

  • 是量子计算的基础

实际应用

  • 量子计算

  • 量子通信

  • 量子密码学

from quonic import qgate, qshow
from quonic.gates import X, H, Z

qgate(X, 0)  # Pauli-X (NOT gate)

原理详解

电路图

数学推导

Pauli-X 门（NOT 门）： \[\begin{equation} X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \end{equation}\] \[\begin{equation} X|0\rangle = |1\rangle, \quad X|1\rangle = |0\rangle \end{equation}\]

Hadamard 门： \[\begin{equation} H = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix} \end{equation}\] \[\begin{equation} H|0\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}}, \quad H|1\rangle = \frac{|0\rangle - |1\rangle}{\sqrt{2}} \end{equation}\]

Pauli-Z 门（相位翻转）： \[\begin{equation} Z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix} \end{equation}\] \[\begin{equation} Z|0\rangle = |0\rangle, \quad Z|1\rangle = -|1\rangle \end{equation}\]

Pauli-Y 门： \[\begin{equation} Y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix} \end{equation}\] \[\begin{equation} Y|0\rangle = i|1\rangle, \quad Y|1\rangle = -i|0\rangle \end{equation}\]

S 门（相位门）： \[\begin{equation} S = \begin{pmatrix} 1 & 0 \\ 0 & i \end{pmatrix} \end{equation}\] \[\begin{equation} S|0\rangle = |0\rangle, \quad S|1\rangle = i|1\rangle \end{equation}\]

T 门（\(\pi/8\) 门）： \[\begin{equation} T = \begin{pmatrix} 1 & 0 \\ 0 & e^{i\pi/4} \end{pmatrix} \end{equation}\] \[\begin{equation} T|0\rangle = |0\rangle, \quad T|1\rangle = e^{i\pi/4}|1\rangle \end{equation}\]

几何解释

在 Bloch 球上：

  • X 门：绕 X 轴旋转 \(\pi\)

  • Y 门：绕 Y 轴旋转 \(\pi\)

  • Z 门：绕 Z 轴旋转 \(\pi\)

  • H 门：绕 (X+Z)/\(\sqrt{2}\) 轴旋转 \(\pi\)

  • S 门：绕 Z 轴旋转 \(\pi/2\)

  • T 门：绕 Z 轴旋转 \(\pi/4\)

代码详解

from quonic import qgate, qshow
from quonic.gates import X, H, Z, Y, S, T

# 单量子比特门
qgate(X, 0)  # Pauli-X: |0> -> |1>, |1> -> |0>
qgate(H, 0)  # Hadamard: |0> -> (|0>+|1>)/sqrt(2)
qgate(Z, 0)  # Pauli-Z: |0> -> |0>, |1> -> -|1>
qgate(Y, 0)  # Pauli-Y: |0> -> i|1>, |1> -> -i|0>
qgate(S, 0)  # S gate: |0> -> |0>, |1> -> i|1>
qgate(T, 0)  # T gate: |0> -> |0>, |1> -> e^(i*pi/4)|1>

qshow()

进阶用法

场景 1：受控门

from quonic.gates import CX, CZ, CY

# CNOT gate
qgate(CX, 0, 1)  # Control: q0, Target: q1

# Controlled-Z gate
qgate(CZ, 0, 1)  # Control: q0, Target: q1

# Controlled-Y gate
qgate(CY, 0, 1)  # Control: q0, Target: q1

场景 2：旋转门

from quonic.gates import Rx, Ry, Rz
import math

# Rx gate: rotation around X axis
qgate(Rx(math.pi/2), 0)  # Rotate pi/2 around X

# Ry gate: rotation around Y axis
qgate(Ry(math.pi/4), 0)  # Rotate pi/4 around Y

# Rz gate: rotation around Z axis
qgate(Rz(math.pi), 0)  # Rotate pi around Z

场景 3：多量子比特门

from quonic.gates import CCX, CSWAP

# Toffoli gate (CCX)
qgate(CCX, 0, 1, 2)  # Control: q0, q1; Target: q2

# Fredkin gate (CSWAP)
qgate(CSWAP, 0, 1, 2)  # Control: q0; Swap: q1, q2

量子密码学

量子门用于量子密钥分发和量子加密。

常见问题

量子门和经典门有什么区别？

量子门是可逆的，经典门是不可逆的。量子门可以创建叠加态和纠缠态。

哪些门是通用的？

{H, T, CNOT} 构成通用量子门集。任何量子电路都可以用这些门近似。

量子门的矩阵表示是什么？

量子门用酉矩阵表示，满足 \(U^\dagger U = I\)。
