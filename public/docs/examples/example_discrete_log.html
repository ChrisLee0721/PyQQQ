为什么需要？

离散对数问题是密码学的基础，量子算法可以高效求解。

经典局限

  • 经典算法需要指数时间

  • 对于大数，经典方法效率低

量子优势

  • 量子算法可以在多项式时间内求解

  • 提供指数加速

  • 是量子密码学的基础

实际应用

  • 密码学

  • 密钥交换

  • 数字签名

原理详解

电路图

数学推导

离散对数问题：给定 \(g, h, p\)，求 \(x\) 使得 \(g^x \equiv h \pmod{p}\)。

量子算法：

  1. 用 QPE 估计周期

  2. 用经典后处理求解

几何解释

离散对数在有限域上求解，利用量子傅里叶变换提取周期信息。

代码详解

from quonic.algorithms import discrete_log

# g: generator
# h: target value
# p: modulus

print(f'x = {result.x}')

密钥交换

常见问题

离散对数和大数分解有什么关系？

都基于周期查找问题，可以用 Shor 算法求解。

量子算法的加速比是多少？

指数加速：\(O(\text{poly}(\log N))\) vs \(O(\exp(\sqrt{\log N}))\)。
