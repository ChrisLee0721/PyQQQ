为什么需要？

离散对数问题是密码学的基础，量子算法可以高效求解。

经典局限

  • 经典算法需要指数时间，对于 \(n\) 位数需要 \(O(\exp(\sqrt{n}))\) 时间

  • 对于大数，经典方法效率低

  • 经典算法无法利用量子并行性

量子优势

  • 量子算法可以在多项式时间内求解，对于 \(n\) 位数需要 \(O(n^3)\) 时间

  • 提供指数加速

  • 是量子密码学的基础

实际应用

  • 密码学（Diffie-Hellman 密钥交换）

  • 数字签名（DSA、ECDSA）

  • 椭圆曲线密码学

快速上手

from quonic.algorithms import discrete_log

# 求解离散对数：2^x ≡ 8 (mod 11)
result = discrete_log(g=2, h=8, p=11)
print(f'x = {result.x}')

预期输出：

x = 3

原理详解

电路图

数学推导

Step 1: 问题定义

给定 \(g, h, p\)，求 \(x\) 使得： \[\begin{equation} g^x \equiv h \pmod{p} \end{equation}\]

Step 2: 量子算法

使用 Shor 算法的变体：

  1. 选择随机 \(a\)

  2. 用 QPE 估计 \(g^a \mod p\) 的阶 \(r\)

  3. 计算 \(x = a \cdot r^{-1} \mod (p-1)\)

Step 3: QPE 估计阶

QPE 估计阶 \(r\)： \[\begin{equation} |0\rangle|1\rangle \to \sum_k |k\rangle|g^k \mod p\rangle \end{equation}\]

测量第一个寄存器得到 \(k\)，用连分数展开求 \(r\)。

Step 4: 经典后处理

计算离散对数： \[\begin{equation} x = a \cdot r^{-1} \mod (p-1) \end{equation}\]

几何解释

离散对数在有限域上求解，利用量子傅里叶变换提取周期信息。

进阶用法

场景 1：Diffie-Hellman 密钥交换

模拟 Diffie-Hellman 密钥交换协议：

from quonic.algorithms import discrete_log

# Diffie-Hellman 参数
p = 23  # 素数
g = 5   # 生成元

# Alice 选择私钥 a，计算公钥 A = g^a mod p
a = 6
A = pow(g, a, p)  # A = 5^6 mod 23 = 8

# Bob 选择私钥 b，计算公钥 B = g^b mod p
b = 15
B = pow(g, b, p)  # B = 5^15 mod 23 = 19

# 共享密钥计算
# Alice: s = B^a mod p
s_alice = pow(B, a, p)

# Bob: s = A^b mod p
s_bob = pow(A, b, p)

print(f'Alice shared key: {s_alice}')
print(f'Bob shared key: {s_bob}')
print(f'Keys match: {s_alice == s_bob}')

# 量子攻击：使用 Shor 算法求解离散对数
# 从公钥 A 恢复私钥 a
result = discrete_log(g=g, h=A, p=p)
print(f'Quantum attack: recovered a = {result.x}')

场景 2：椭圆曲线密码学

椭圆曲线离散对数问题（ECDLP）：

from quonic.algorithms import discrete_log

# 椭圆曲线参数（简化示例）
# y^2 = x^3 + ax + b mod p
a = 2
b = 3
p = 97

# 基点 G = (3, 6)
Gx, Gy = 3, 6

# Alice 私钥 n_A，公钥 Q_A = n_A * G
n_A = 7
# 计算 Q_A = n_A * G（椭圆曲线点乘）
# 简化：使用标量乘法
Q_Ax, Q_Ay = (n_A * Gx) % p, (n_A * Gy) % p

# 量子攻击：求解 ECDLP
# 从 Q_A 恢复 n_A
# 这比经典攻击快指数倍
print(f'Public key Q_A: ({Q_Ax}, {Q_Ay})')
print(f'Private key n_A: {n_A}')

# 经典攻击：需要 O(sqrt(p)) 时间
# 量子攻击：需要 O(log(p)) 时间

场景 3：数字签名验证

使用离散对数进行数字签名：

from quonic.algorithms import discrete_log
import hashlib

# DSA 签名参数
p = 23
g = 5
q = 11  # (p-1) 的因子

# 密钥生成
x = 7  # 私钥
y = pow(g, x, p)  # 公钥

# 签名过程
message = "Hello, Quantum World!"
k = 3  # 随机数

r = pow(g, k, p) % q
k_inv = pow(k, -1, q)
hash_msg = int(hashlib.sha256(message.encode()).hexdigest(), 16) % q
s = (k_inv * (hash_msg + x * r)) % q

print(f'Signature: (r={r}, s={s})')

# 验证过程
w = pow(s, -1, q)
u1 = (hash_msg * w) % q
u2 = (r * w) % q
v = (pow(g, u1, p) * pow(y, u2, p)) % p % q

print(f'Verification: v={v}, r={r}')
print(f'Signature valid: {v == r}')

# 量子攻击：可以从公钥 y 恢复私钥 x
result = discrete_log(g=g, h=y, p=p)
print(f'Quantum attack: recovered x = {result.x}')

适用场景

密钥交换协议

离散对数是 Diffie-Hellman 密钥交换协议的基础。量子计算机可以高效求解离散对数，威胁传统密钥交换的安全性。

数字签名系统

离散对数是 DSA 和 ECDSA 数字签名算法的基础。量子计算机可以伪造数字签名，需要迁移到后量子密码学。

区块链安全

离散对数是区块链安全的基础。比特币、以太坊使用 ECDSA 签名验证交易，量子计算机可以从公钥恢复私钥。

后量子密码学迁移

离散对数问题的量子可解性推动了后量子密码学的发展。NIST 已经标准化了新的抗量子算法（如 CRYSTALS-Kyber）。

椭圆曲线密码学

椭圆曲线离散对数问题是椭圆曲线密码学的基础。

常见问题

离散对数和大数分解有什么关系？

都基于周期查找问题，可以用 Shor 算法求解。

量子算法的加速比是多少？

指数加速：\(O(\text{poly}(\log N))\) vs \(O(\exp(\sqrt{\log N}))\)。

离散对数问题的难度如何？

离散对数问题是 NP-hard 的，但不是 NP-complete 的。
