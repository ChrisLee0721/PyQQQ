为什么需要？

量子 TDA 是经典 TDA 的量子推广，用于分析数据的拓扑结构。

经典局限

  • 经典 TDA 计算持久同调慢

  • 对于大规模数据，经典方法效率低

量子优势

  • 量子 TDA 可以在量子计算机上高效计算持久同调

  • 提供指数加速

  • 是量子拓扑学的基础

实际应用

  • 数据分析

  • 机器学习

  • 材料科学

快速上手

from quonic.ml import qtda

# 量子拓扑数据分析
data = [[0, 1], [1, 0], [1, 1], [0, 0]]
result = qtda(data)
print(f'Betti numbers: {result.betti}')

预期输出：

Betti numbers: [1, 0]

电路图

数学推导

量子 TDA 基于量子相位估计： \[\begin{equation} |0\rangle|\psi\rangle \to |\tilde{\lambda}\rangle|\psi\rangle \end{equation}\]

持久同调： \[\begin{equation} H_k(X_\epsilon) \to H_k(X_{\epsilon'}) \end{equation}\]

几何解释

量子 TDA 在量子态空间中分析数据的拓扑结构。量子相位估计可以高效计算持久同调。

代码详解

from quonic.ml import qtda

# qtda(data, max_dimension)
# data: 输入数据
# max_dimension: 最大维度
result = qtda(data, max_dimension=2)

# result.betti: Betti 数
# result.persistence: 持久图
print(f'Betti numbers: {result.betti}')

适用场景

数据分析

量子 TDA 可以分析数据的拓扑结构，如孔洞、连通分量等。传统 TDA 计算慢，量子 TDA 可以提供指数加速。

材料科学

量子 TDA 可以分析材料的微观结构。例如，分析多孔材料的孔洞结构、分析晶体的缺陷等。

常见问题

量子 TDA 和经典 TDA 有什么区别？

量子 TDA 使用量子相位估计计算持久同调，可以在 \(O(\log N)\) 时间内完成，经典 TDA 需要 \(O(N^3)\) 时间。

量子 TDA 的精度如何？

精度取决于量子相位估计的精度。
