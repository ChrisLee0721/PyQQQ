为什么需要？

GPU 加速可以显著提高量子模拟的速度。

经典局限

  • CPU 模拟量子电路慢

  • 对于大规模电路，CPU 效率低

量子优势

  • GPU 可以并行处理大量量子态

  • 显著提高模拟速度

  • 适用于大规模量子电路

实际应用

  • 量子模拟

  • 量子算法开发

  • 量子硬件测试

快速上手

from quonic import qgate, qshow
from quonic.gates import H

# GPU 加速
qgate(H, 0)
qshow(backend='gpu')

预期输出：

backend: gpu | shots: 1024
Result:
  |0>     512  ( 50.0%)
  |1>     512  ( 50.0%)

原理详解

电路图

数学推导

GPU 加速： \[\begin{equation} \text{Speedup} = \frac{T_{\text{CPU}}}{T_{\text{GPU}}} \end{equation}\]

几何解释

GPU 可以并行处理大量量子态。每个 GPU 核心可以处理一个量子态分量。

代码详解

from quonic import qgate, qshow
from quonic.gates import H

# GPU 后端
qgate(H, 0)
qshow(backend='gpu')

# CPU 后端（对比）
qshow(backend='native')

进阶用法

场景 1：大规模电路

from quonic import qgate, qshow
from quonic.gates import H, CX

# 大规模电路
for i in range(20):
    qgate(H, i)
for i in range(19):
    qgate(CX, i, i+1)
qshow(backend='gpu')

适用场景

量子模拟

GPU 加速可以显著提高量子模拟的速度。对于大规模量子电路，GPU 比 CPU 快得多。

量子算法开发

GPU 加速可以加快量子算法的开发和测试。

常见问题

GPU 加速需要什么硬件？

GPU 加速需要 NVIDIA GPU 和 CUDA 支持。

GPU 加速的性能如何？

GPU 加速的性能取决于 GPU 型号和电路规模。对于大规模电路，GPU 可以比 CPU 快 10-100 倍。
