为什么需要？

量子玻尔兹曼机是经典玻尔兹曼机的量子推广。

经典局限

  • 经典玻尔兹曼机训练慢

  • 对于复杂分布，经典方法效率低

量子优势

  • 量子玻尔兹曼机可以利用量子叠加和纠缠

  • 训练速度更快

  • 可以表示更复杂的分布

实际应用

  • 机器学习

  • 生成模型

  • 优化

快速上手

from quonic.ml import qbm
result = qbm(data=[[0,1],[1,0]], n_hidden=2)
print(f'Trained: {result.model}')

预期输出：

Trained: QBM(n_visible=2, n_hidden=2)

原理详解

电路图

数学推导

量子玻尔兹曼机： \[\begin{equation} \rho = e^{-\beta H} / Z \end{equation}\]

其中 \(H\) 是哈密顿量，\(Z\) 是配分函数。

几何解释

量子玻尔兹曼机在量子态空间中学习概率分布。

代码详解

from quonic.ml import qbm

# qbm(data, n_hidden, n_epochs)
# data: training data
# n_hidden: number of hidden units
# n_epochs: number of training epochs
result = qbm(data=[[0,1],[1,0]], n_hidden=2)
print(f'Trained: {result.model}')
