为什么需要？

量子玻尔兹曼机是经典玻尔兹曼机的量子推广。

经典局限

  • 经典玻尔兹曼机训练慢

  • 对于复杂分布，经典方法效率低

  • 经典玻尔兹曼机容易陷入局部最优

量子优势

  • 量子玻尔兹曼机可以利用量子叠加和纠缠

  • 训练速度更快

  • 可以表示更复杂的分布

实际应用

  • 机器学习（生成模型）

  • 优化（组合优化）

  • 量子化学（分子模拟）

原理详解

电路图

数学推导

Step 1: 量子玻尔兹曼机

量子玻尔兹曼机： \[\begin{equation} \rho = \frac{e^{-\beta H}}{Z} \end{equation}\]

其中 \(H\) 是哈密顿量，\(Z = \text{Tr}(e^{-\beta H})\) 是配分函数。

Step 2: 哈密顿量

哈密顿量： \[\begin{equation} H = \sum_i h_i Z_i + \sum_{ij} J_{ij} Z_i Z_j + \sum_i \Delta_i X_i \end{equation}\]

Step 3: 自由能

自由能： \[\begin{equation} F = -\frac{1}{\beta} \ln Z \end{equation}\]

Step 4: 训练

训练目标是最小化自由能： \[\begin{equation} \theta^* = \arg\min_\theta F(\theta) \end{equation}\]

Step 5: 梯度

梯度： \[\begin{equation} \frac{\partial F}{\partial \theta_i} = \langle\frac{\partial H}{\partial \theta_i}\rangle_\rho \end{equation}\]

几何解释

量子玻尔兹曼机在量子态空间中学习概率分布。量子叠加允许同时探索多个状态，量子纠缠允许表示复杂的关联。

代码详解

from quonic.ml import qbm

# qbm(data, n_hidden, n_epochs, learning_rate)
# data: 训练数据
# n_hidden: 隐藏单元数
# n_epochs: 训练轮数
# learning_rate: 学习率

result = qbm(
    data=[[0, 1], [1, 0], [1, 1], [0, 0]],
    n_hidden=2,
    n_epochs=100,
    learning_rate=0.01
)

# result.model: 训练后的模型
# result.loss: 损失值
# result.params: 参数
# result.history: 训练历史
print(f'Trained: {result.model}')
print(f'Loss: {result.loss}')

进阶用法

场景 1：二值图像生成

使用 QBM 学习和生成二值图像：

from quonic.ml import qbm
import numpy as np
import matplotlib.pyplot as plt

# 训练数据：简单的 4x4 二值图像
# 图案：十字形
cross_pattern = [
    [0, 0, 1, 0],
    [0, 0, 1, 0],
    [1, 1, 1, 1],
    [0, 0, 1, 0]
]

# 展平为 1 维
data = [np.array(cross_pattern).flatten().tolist()]

# 训练 QBM
result = qbm(data=data, n_hidden=4, n_epochs=200)

# 生成新样本
generated_samples = result.sample(n_samples=5)

# 可视化
fig, axes = plt.subplots(1, 6, figsize=(12, 2))
axes[0].imshow(cross_pattern, cmap='gray')
axes[0].set_title('Original')
axes[0].axis('off')

for i, sample in enumerate(generated_samples):
    axes[i+1].imshow(np.array(sample).reshape(4, 4), cmap='gray')
    axes[i+1].set_title(f'Generated {i+1}')
    axes[i+1].axis('off')

plt.savefig('qbm_generation.png')
plt.show()

# 分析：QBM 学习了数据的分布，可以生成相似的图案

场景 2：异常检测

使用 QBM 进行异常检测：

from quonic.ml import qbm
import numpy as np

# 正常数据：简单的模式
normal_data = [
    [1, 0, 1, 0],
    [0, 1, 0, 1],
    [1, 1, 0, 0],
    [0, 0, 1, 1]
]

# 训练 QBM 学习正常数据的分布
qbm_model = qbm(data=normal_data, n_hidden=2, n_epochs=200)

# 测试数据
test_data = [
    [1, 0, 1, 0],  # 正常
    [1, 1, 1, 1],  # 异常（全 1）
    [0, 1, 0, 1],  # 正常
    [1, 0, 0, 0],  # 异常（不常见模式）
]

# 计算每个样本的能量（负对数似然）
for i, sample in enumerate(test_data):
    energy = qbm_model.energy(sample)
    is_anomaly = energy > qbm_model.threshold

    print(f'Sample {i}: Energy={energy:.4f}, Anomaly={is_anomaly}')

# 分析：
# - 正常样本的能量较低（高概率）
# - 异常样本的能量较高（低概率）
# - 可以通过设置阈值来检测异常

场景 3：量子优势分析

比较量子和经典玻尔兹曼机：

from quonic.ml import qbm
import numpy as np
import time

# 生成复杂数据
np.random.seed(42)
n_samples = 50
n_features = 8

# 具有复杂相关性的数据
data = []
for _ in range(n_samples):
    # 创建具有非平凡相关性的样本
    x = np.random.randint(0, 2, n_features)
    # 添加相关性：如果前 4 位有偶数个 1，后 4 位也应有偶数个 1
    parity = sum(x[:4]) % 2
    if parity == 0:
        x[4:] = [b if b == 0 else 0 for b in x[4:]]
    data.append(x.tolist())

# 量子玻尔兹曼机
start_qbm = time.time()
qbm_result = qbm(data=data, n_hidden=4, n_epochs=100)
time_qbm = time.time() - start_qbm

# 经典玻尔兹曼机（对比）
from quonic.ml import rbm
start_rbm = time.time()
rbm_result = rbm(data=data, n_hidden=4, n_epochs=100)
time_rbm = time.time() - start_rbm

print(f'QBM: Loss={qbm_result.loss:.4f}, Time={time_qbm:.2f}s')
print(f'RBM: Loss={rbm_result.loss:.4f}, Time={time_rbm:.2f}s')
print(f'QBM vs RBM: {rbm_result.loss/qbm_result.loss:.2f}x better')

# 分析：
# - QBM 可以学习更复杂的分布（量子纠缠）
# - 对于具有非平凡相关性的数据，QBM 可能更好
# - 但 QBM 的训练时间可能更长

适用场景

图像生成

量子玻尔兹曼机可以学习图像数据的分布并生成新样本。QBM 可以利用量子纠缠表示比经典 RBM 更复杂的分布。

异常检测

量子玻尔兹曼机可以学习正常数据的分布，检测异常数据。QBM 对异常数据的能量值更高，可以用于网络安全、金融风控等场景。

推荐系统

量子玻尔兹曼机可以学习用户-商品交互的分布，预测用户可能感兴趣的商品。QBM 可以利用量子纠缠捕捉用户偏好的复杂模式。

药物发现

量子玻尔兹曼机可以学习药物分子的分布，生成具有特定性质的新分子。QBM 可以利用量子叠加探索更大的分子空间。
