为什么需要？

多经典寄存器用于在量子程序中存储多个测量结果。

经典局限

  • 单个经典寄存器只能存储一个测量结果

  • 需要多个寄存器存储多个结果

量子优势

  • 多经典寄存器可以存储多个测量结果

  • 支持复杂量子算法

  • 是量子程序的基础组件

实际应用

  • 量子算法

  • 量子纠错

  • 量子通信

快速上手

from quonic import qgate, qshow
from quonic.gates import H

# 多经典寄存器
qgate(H, 0)
qgate(H, 1)

原理详解

电路图

数学推导

多经典寄存器： \[\begin{equation} \text{creg} = [c_0, c_1, \ldots, c_{n-1}] \end{equation}\]

其中 \(c_i\) 是经典比特。

几何解释

多经典寄存器在测量后存储多个经典比特。每个量子比特对应一个经典比特。

代码详解

from quonic import qgate, qshow
from quonic.gates import H

# 多量子比特测量
qgate(H, 0)
qgate(H, 1)

# qshow() 返回所有量子比特的测量结果
qshow()

进阶用法

场景 1：部分测量

from quonic import qgate, qshow
from quonic.gates import H

# 部分测量
qgate(H, 0)
qgate(H, 1)
qshow(measure=[0])  # 只测量 q0

适用场景

量子算法

多经典寄存器用于存储量子算法的多个测量结果。例如，Shor 算法需要存储多个量子比特的测量结果。

量子纠错

多经典寄存器用于存储量子纠错的伴随子测量结果。

常见问题

多经典寄存器和单经典寄存器有什么区别？

多经典寄存器可以存储多个测量结果，单经典寄存器只能存储一个。

如何访问多经典寄存器？

可以通过索引访问多经典寄存器。例如，result[0] 访问第一个经典比特。
