Algorithms / 算法 | 难度：高级 | 预计时间：20 分钟

为什么需要？

量子本征值估计是量子相位估计的推广，用于估计算子的本征值。

经典局限

  • 经典本征值估计需要 \(O(N^3)\) 时间

  • 对于大规模矩阵，经典方法效率低

量子优势

  • 量子本征值估计需要 \(O(\text{poly}(\log N))\) 时间

  • 对于稀疏矩阵，提供指数加速

  • 是量子化学和量子机器学习的基础

实际应用

  • 量子化学（分子能量计算）

  • 量子机器学习（核方法）

  • 量子模拟（哈密顿量模拟）

快速上手

from quonic.algorithms import quantum_eigenvalue

# Estimate eigenvalues
A = [[1, 0], [0, 2]]
result = quantum_eigenvalue(A)
print(f"Eigenvalues: {result.eigenvalues}")

预期输出：

Eigenvalues: [1.0, 2.0]

原理详解

电路图

数学推导

量子本征值估计估计 \(A\) 的本征值： \[\begin{equation} A|v_i\rangle = \lambda_i|v_i\rangle \end{equation}\]

算法步骤：

  1. 用 QPE 估计 \(A\) 的本征值 \(\lambda_i\)

  2. 测量得到本征值

几何解释

量子本征值估计在量子态空间中操作，通过 QPE 将矩阵对角化，然后测量得到本征值。

代码详解

from quonic.algorithms import quantum_eigenvalue

# result.eigenvalues: estimated eigenvalues

print(f"Eigenvalues: {result.eigenvalues}")

适用场景

量子机器学习

常见问题

量子本征值估计的加速比是多少？

指数加速：\(O(\text{poly}(\log N))\) vs \(O(N^3)\)。

量子本征值估计的局限性是什么？

需要矩阵是稀疏的，且条件数不能太大。
