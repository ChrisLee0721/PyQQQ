Why do we need it?

Finding a target in an unsorted database requires \(O(N)\) queries classically, but Grover’s algorithm only needs \(O(\sqrt{N})\).

Classical Limitations

  • Classical search: worst case requires traversing all \(N\) elements

  • For \(N=10^6\), classical needs \(10^6\) queries, quantum only \(10^3\)

Quantum Advantages

  • Quadratic speedup: \(O(\sqrt{N})\) vs \(O(N)\)

  • Significant speedup for large-scale search problems

  • Foundation for many quantum algorithms (amplitude amplification, quantum counting)

Real-world Applications

  • Database search

  • Cryptography (searching key space)

  • Optimization problems (finding optimal solutions)

  • SAT solving

Quick Start

from quonic.algorithms import grover

# Search for |11> in 2-qubit space
result = grover("11", 2, shots=1024)
print(result.counts)

Expected Output:

{'11': 1008, '00': 6, '01': 5, '10': 5}

Theory Deep Dive

Circuit Diagram

Mathematical Derivation

Step 1: Initialization

Apply \(H\) gate to all qubits, creating uniform superposition: \[\begin{equation} |\psi_0\rangle = \frac{|00\rangle + |01\rangle + |10\rangle + |11\rangle}{2} \end{equation}\]

Step 2: Oracle Marking

Oracle flips the phase of target state \(|11\rangle\): \[\begin{equation} |\psi_1\rangle = \frac{|00\rangle + |01\rangle + |10\rangle - |11\rangle}{2} \end{equation}\]

Step 3: Diffusion Operator

Diffusion operator reflects about the mean amplitude:

  • Mean amplitude = \((1/4 + 1/4 + 1/4 - 1/4)/4 = 1/8\)

  • After reflection: \(|11\rangle\) amplitude is amplified

Step 4: Iteration

Repeat Oracle + Diffusion, each iteration amplifies target state amplitude.

Step 5: Measurement

Optimal iterations \(\approx \pi\sqrt{N}/4\), target state probability \(\approx 100\%\).

Geometric Interpretation

Grover’s algorithm in Bloch sphere: each iteration rotates the quantum state, amplifying the target state amplitude.

Like swinging on a swing — each push increases the amplitude.

FAQ

What is the speedup of Grover search?

Quadratic speedup: \(O(\sqrt{N})\) vs \(O(N)\). For \(N=10^6\), classical needs \(10^6\) queries, quantum only \(10^3\).

How many iterations does Grover search need?

Optimal iterations \(\approx \pi\sqrt{N}/4\). For \(N=4\) (2 qubits), only 1 iteration needed.

Can Grover search find all targets?

Grover search finds one target. To find all targets, multiple runs are needed.

What are the limitations of Grover search?

1) Need target state description; 2) Only finds one target; 3) For small problems, classical may be faster.

What’s the difference between Grover search and amplitude amplification?

Grover search is amplitude amplification with uniform initial state. Amplitude amplification is more general, supports arbitrary initial states.
