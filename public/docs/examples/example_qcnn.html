ML / 机器学习 | 难度：高级 | 预计时间：20 分钟

为什么需要？

量子卷积神经网络是经典 CNN 的量子推广。

经典局限

  • 经典 CNN 训练慢

  • 对于高维数据，经典方法效率低

量子优势

  • 量子 CNN 可以处理指数维的特征空间

  • 训练速度更快

  • 可以提取更复杂的特征

实际应用

  • 图像识别

  • 模式分类

  • 量子机器学习

快速上手

from quonic.ml import qcnn
result = qcnn(data=[[0,1],[1,0]], n_layers=2)
print(f'Output: {result.output}')

预期输出：

Output: [0.5, 0.5]

原理详解

电路图

数学推导

量子卷积： \[\begin{equation} U_{conv} = \prod_i U_i(\theta) \end{equation}\]

量子池化： \[\begin{equation} U_{pool} = \text{CNOT}_{i,j} \end{equation}\]

几何解释

量子卷积在量子态空间中提取特征。

代码详解

from quonic.ml import qcnn

# qcnn(data, n_layers)
# data: input data
# n_layers: number of convolution layers
result = qcnn(data=[[0,1],[1,0]], n_layers=2)
print(f'Output: {result.output}')
