为什么需要？

量子强化学习是经典强化学习的量子推广，用于在量子环境中学习最优策略。

经典局限

  • 经典强化学习在高维状态空间中学习慢

  • 对于复杂环境，经典方法效率低

量子优势

  • 量子强化学习可以利用量子叠加探索更大的状态空间

  • 学习速度更快

  • 可以处理更复杂的环境

实际应用

  • 游戏 AI

  • 机器人控制

  • 量子控制

快速上手

from quonic.ml import qrl

# 量子强化学习
result = qrl(env='gridworld', n_episodes=100)
print(f'Reward: {result.reward}')

原理详解

电路图

数学推导

量子强化学习基于量子策略： \[\begin{equation} \pi(a|s) = |\langle a|U(\theta)|s\rangle|^2 \end{equation}\]

更新规则： \[\begin{equation} \theta_{t+1} = \theta_t + \alpha \nabla_\theta J(\theta) \end{equation}\]

几何解释

量子强化学习在量子态空间中学习策略。量子叠加允许同时探索多个动作。

代码详解

from quonic.ml import qrl

# qrl(env, n_episodes, learning_rate)
# env: 环境
# n_episodes: 训练轮数
# learning_rate: 学习率
result = qrl(env='gridworld', n_episodes=100)

# result.reward: 累积奖励
# result.policy: 学习到的策略
# result.history: 训练历史
print(f'Reward: {result.reward}')
