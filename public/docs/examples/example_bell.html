Why do we need it?

In classical physics, two objects have independent states — measuring one does not affect the other. But in the quantum world, two qubits can enter an entangled state: measuring one instantly determines the state of the other.

Classical Limitations

  • Classical physics cannot create such “spooky action at a distance”

  • Classical communication requires at least 2 bits to transmit 1 bit of quantum information

Quantum Advantages

  • Bell state is the most basic form of quantum entanglement

  • Violates Bell inequalities, proving quantum mechanics is non-local

  • Foundation for quantum teleportation, superdense coding, and QKD

Real-world Applications

  • Quantum Key Distribution (BB84, E91 protocols)

  • Quantum Teleportation (foundation of quantum networks)

  • Quantum Computing (entanglement resource)

Quick Start

from quonic import qgate, qshow
from quonic.gates import CX, H

# Create Bell state
qgate(H, 0)      # Hadamard gate: create superposition
qgate(CX, 0, 1)  # CNOT gate: create entanglement
qshow()           # Measure and display results

Expected Output:

backend: native | shots: 1024
Result:
  |00>     512  ( 50.0%)  ####################
  |11>     512  ( 50.0%)  ####################

Theory Deep Dive

Circuit Diagram

Mathematical Derivation

Step 1: Initial State

Both qubits start from \(|0\rangle\): \[\begin{equation} |\psi_0\rangle = |00\rangle \end{equation}\]

Step 2: Hadamard Gate

Apply \(H\) gate to \(q_0\): \[\begin{equation} H|0\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}} \end{equation}\]

State becomes: \[\begin{equation} |\psi_1\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}} \otimes |0\rangle = \frac{|00\rangle + |10\rangle}{\sqrt{2}} \end{equation}\]

Step 3: CNOT Gate

CNOT gate rule: if control qubit is \(|1\rangle\), flip target qubit. \[\begin{align} \text{CNOT}|00\rangle &= |00\rangle \\ \text{CNOT}|10\rangle &= |11\rangle \end{align}\]

Final state: \[\begin{equation} |\psi_2\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}} \end{equation}\]

Step 4: Measurement Probabilities

  • \(P(|00\rangle) = |1/\sqrt{2}|^2 = 0.5\)

  • \(P(|11\rangle) = |1/\sqrt{2}|^2 = 0.5\)

  • \(P(|01\rangle) = 0\)

  • \(P(|10\rangle) = 0\)

Geometric Interpretation

On the Bloch sphere:

  • \(|0\rangle\) at the north pole

  • \(|1\rangle\) at the south pole

  • \(H\) gate rotates \(|0\rangle\) to the equator: \(|+\rangle = (|0\rangle+|1\rangle)/\sqrt{2}\)

After CNOT creates entanglement, the two qubits can no longer be described by individual Bloch spheres — they become one entity. This is the geometric meaning of entanglement.

Code Walkthrough

from quonic import qgate, qshow  # Import core API
from quonic.gates import CX, H   # Import gate definitions

# qgate(gate, qubit) - Apply gate to specified qubit
qgate(H, 0)      # Apply H gate to q0
                  # H gate: |0> -> (|0>+|1>)/sqrt(2)
                  # Effect: create superposition

# qgate(gate, control, target) - Apply controlled gate
qgate(CX, 0, 1)  # CNOT gate: control=q0, target=q1
                  # Effect: if q0 is |1>, flip q1
                  # Create entangled state (|00>+|11>)/sqrt(2)

# qshow() - Run circuit and display results
qshow()           # Auto-select best backend
                  # Execute 1024 measurements
                  # Display measurement statistics

API Reference

API Parameters Description
qgate(H, 0) H: Hadamard gate, 0: qubit index Apply H gate to q0
qgate(CX, 0, 1) CX: CNOT gate, 0: control, 1: target Create entanglement
qshow() None Run circuit and display results

Advanced Usage

Scenario 1: Different Bell States

# Phi+ = (|00>+|11>)/sqrt(2)
qgate(H, 0)
qgate(CX, 0, 1)

# Phi- = (|00>-|11>)/sqrt(2)
qgate(H, 0)
qgate(X, 0)  # Phase flip
qgate(CX, 0, 1)

# Psi+ = (|01>+|10>)/sqrt(2)
qgate(H, 0)
qgate(CX, 0, 1)
qgate(X, 1)  # Flip q1

# Psi- = (|01>-|10>)/sqrt(2)
qgate(H, 0)
qgate(X, 0)
qgate(CX, 0, 1)
qgate(X, 1)

Scenario 2: Multi-qubit GHZ State

# GHZ state: (|000>+|111>)/sqrt(2)
qgate(H, 0)
qgate(CX, 0, 1)
qgate(CX, 1, 2)
qshow()

Scenario 3: Noisy Bell State

# No noise
qshow(noise=0)

# 5% noise
qshow(noise=0.05)

# 20% noise
qshow(noise=0.20)

Use Cases

Quantum Key Distribution

BB84 and E91 protocols use Bell states to detect eavesdropping. If someone tries to measure the quantum state, it destroys the entanglement, and both parties can detect it.

Quantum Teleportation

Quantum teleportation uses Bell states as a quantum channel to transfer quantum states without directly transmitting qubits.

Quantum Computing Testing

Bell states are the gold standard for testing quantum hardware quality. If hardware cannot correctly prepare Bell states, it indicates noise or calibration issues.

FAQ

Why is my result not exactly 50/50?

Quantum measurements have inherent randomness. Even with theoretical 50/50 probabilities, finite measurements (e.g., 1024 shots) will have statistical fluctuations. Increasing the number of shots gets closer to theoretical values.

Why did I see |01> or |10>?

Possible causes: 1) Noise (check if noise parameter is set); 2) Code error (verify H gate comes before CNOT); 3) Backend issue (try backend=’native’).

What’s the difference between Bell state and GHZ state?

Bell state is 2-qubit entanglement, GHZ state is 3+ qubit entanglement. GHZ state is a generalization of Bell state for multi-party quantum communication and quantum error correction.

How to verify I prepared a Bell state?

Check measurement results: 1) Only |00> and |11>; 2) Both probabilities close to 50%; 3) No |01> or |10>. If all three conditions are met, it’s a Bell state.

What does Bell inequality violation mean?

In classical physics, two particles have a correlation limit (Bell inequality). Quantum mechanics predictions exceed this limit, and experiments confirm quantum mechanics. This means no local hidden variable theory can explain quantum correlations.
