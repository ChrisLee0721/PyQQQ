\section{Why do we need it?}

Bernstein-Vazirani algorithm is a generalization of Deutsch-Jozsa, used to find hidden bit strings.

\subsection{Classical Limitations}
\begin{itemize}
  \item Classical algorithm needs $n$ queries to find hidden bit string
  \item Each query only yields 1 bit of information
\end{itemize}

\subsection{Quantum Advantages}
\begin{itemize}
  \item Bernstein-Vazirani only needs 1 query
  \item Provides linear speedup
  \item Paradigm for quantum algorithm design
\end{itemize}

\subsection{Real-world Applications}
\begin{itemize}
  \item Quantum algorithm teaching
  \item Quantum advantage verification
  \item Quantum computing theory
\end{itemize}

\subsection{Mathematical Derivation}

Bernstein-Vazirani finds hidden bit string $s$, such that $f(x) = s \cdot x \mod 2$.

\textbf{Step 1: Initialization}
\begin{equation}
|\psi_0\rangle = |0\rangle^{\otimes n}|1\rangle
\end{equation}

\textbf{Step 2: Hadamard Gates}
\begin{equation}
|\psi_1\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle \cdot \frac{|0\rangle - |1\rangle}{\sqrt{2}}
\end{equation}

\textbf{Step 3: Oracle Query}
\begin{equation}
|\psi_2\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} (-1)^{s \cdot x} |x\rangle \cdot \frac{|0\rangle - |1\rangle}{\sqrt{2}}
\end{equation}

\textbf{Step 4: Hadamard and Measurement}

Measurement result is hidden bit string $s$.

\subsection{Geometric Interpretation}

Bernstein-Vazirani uses quantum superposition to query all inputs simultaneously, using interference to extract hidden bit string.

\section{FAQ}

\subsection{What is the speedup of Bernstein-Vazirani?}

Linear speedup: classical needs $n$ queries, quantum only 1.

\subsection{What are the practical applications of Bernstein-Vazirani?}

Bernstein-Vazirani is mainly used for teaching and theoretical research, with limited practical applications.

\subsection{What's the difference between Bernstein-Vazirani and Deutsch-Jozsa?}

Deutsch-Jozsa determines function type, Bernstein-Vazirani finds hidden bit string.
