\section{为什么需要？}

BB84 是第一个量子密钥分发协议，利用量子力学原理实现无条件安全的密钥分发。

\subsection{经典局限}
\begin{itemize}
  \item 经典加密依赖计算复杂度（如 RSA）
  \item 量子计算机可以破解经典加密
  \item 经典密钥分发需要可信信道
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item BB84 提供信息论安全性（不依赖计算复杂度）
  \item 量子不可克隆定理保证窃听可检测
  \item 是后量子密码学的基础
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 量子密钥分发网络
  \item 量子安全通信
  \item 量子互联网
\end{itemize}

\subsection{数学推导}

BB84 协议步骤：
\begin{enumerate}
  \item Alice 随机选择比特和基
  \item Alice 制备量子态并发送给 Bob
  \item Bob 随机选择基测量
  \item Alice 和 Bob 公开比较基
  \item 保留基相同的比特作为密钥
\end{enumerate}

安全性基于量子不可克隆定理：
\begin{equation}
|\psi\rangle \neq |\phi\rangle \Rightarrow \text{无法完美复制}
\end{equation}

\subsection{几何解释}

在 Bloch 球上，BB84 使用两个正交基：
\begin{itemize}
  \item 计算基：$\{|0\rangle, |1\rangle\}$
  \item Hadamard 基：$\{|+\rangle, |-\rangle\}$
\end{itemize}

窃听者不知道 Alice 使用的基，测量会引入错误。

# bb84(n_bits, noise)
# n_bits: number of bits to generate
# noise: channel noise rate

# result.key: shared secret key
# result.error_rate: quantum bit error rate
print(f"Shared key: {result.key}")
print(f"Error rate: {result.error_rate}")

\section{常见问题}

\subsection{BB84 为什么是安全的？}

BB84 的安全性基于量子不可克隆定理。窃听者无法完美复制量子态，测量会引入错误。

\subsection{BB84 的密钥生成率是多少？}

理想情况下，BB84 的密钥生成率约为 50\%（基匹配的概率）。

\subsection{BB84 能抵抗量子计算机吗？}

BB84 提供信息论安全性，不依赖计算复杂度，因此可以抵抗量子计算机。
