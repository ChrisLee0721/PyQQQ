\section{为什么需要？}

量子贝叶斯推断是经典贝叶斯推断的量子推广，用于在量子环境中进行概率推断。

\subsection{经典局限}
\begin{itemize}
  \item 经典贝叶斯推断在高维参数空间中慢
  \item 对于复杂后验分布，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子贝叶斯推断可以利用量子叠加探索更大的参数空间
  \item 推断速度更快
  \item 可以处理更复杂的后验分布
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 统计推断
  \item 机器学习
  \item 量子态层析
\end{itemize}

\subsection{数学推导}

量子贝叶斯推断：
\begin{equation}
P(\theta|D) \propto P(D|\theta) P(\theta)
\end{equation}

\textbf{量子似然}：
\begin{equation}
P(D|\theta) = |\langle D|U(\theta)|0\rangle|^2
\end{equation}

\subsection{几何解释}

量子贝叶斯推断在量子态空间中更新后验分布。量子叠加允许同时探索多个参数值。

\section{代码详解}

\begin{verbatim}
from quonic.ml import quantum_bayesian

# quantum_bayesian(data, prior, n_samples)
# data: 观测数据
# prior: 先验分布
# n_samples: 采样数
result = quantum_bayesian(data=[1, 0, 1, 1], prior='uniform')

# result.posterior: 后验分布
# result.map: MAP 估计
# result.samples: 后验采样
print(f'Posterior: {result.posterior}')
\end{verbatim}
