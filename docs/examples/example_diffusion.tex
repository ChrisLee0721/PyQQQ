\subsection{数学推导}

扩散算子关于平均振幅反射：
\begin{equation}
D = 2|s\rangle\langle s| - I
\end{equation}

其中 $|s\rangle$ 是均匀叠加态。

\textbf{作用}：
\begin{equation}
D|\psi\rangle = 2\langle s|\psi\rangle|s\rangle - |\psi\rangle
\end{equation}

\subsection{几何解释}

扩散算子在 Bloch 球上关于平均振幅反射，放大目标态的振幅。
