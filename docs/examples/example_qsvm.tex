\section{为什么需要？}

量子 SVM 利用量子核函数进行分类，是量子机器学习的核心算法之一。

\subsection{经典局限}
\begin{itemize}
  \item 经典 SVM 核函数计算慢，对于 $N$ 个样本需要 $O(N^2)$ 时间
  \item 经典核函数受限于多项式核、RBF 核等有限类型
  \item 对于高维数据，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子 SVM 可以在指数维的 Hilbert 空间中计算核函数
  \item 量子核函数可以表示经典核函数无法表示的复杂模式
  \item 对于某些问题，量子 SVM 提供指数加速
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 二分类问题（如图像分类、文本分类）
  \item 多分类问题（如手写数字识别）
  \item 异常检测（如金融欺诈检测）
  \item 特征提取（如量子特征映射）
\end{itemize}

\subsection{数学推导}

\textbf{Step 1: 量子特征映射}

将经典数据 $x$ 映射到量子态：
\begin{equation}
|\phi(x)\rangle = U(x)|0\rangle^{\otimes n}
\end{equation}

其中 $U(x)$ 是参数化量子电路。

\textbf{Step 2: 量子核函数}

量子核函数定义为两个量子态的内积：
\begin{equation}
K(x_i, x_j) = |\langle\phi(x_i)|\phi(x_j)\rangle|^2
\end{equation}

这可以重写为：
\begin{equation}
K(x_i, x_j) = |\langle 0|^{\otimes n} U^\dagger(x_i) U(x_j) |0\rangle^{\otimes n}|^2
\end{equation}

\textbf{Step 3: 核矩阵计算}

对于 $N$ 个样本，计算 $N \times N$ 的核矩阵：
\begin{equation}
K_{ij} = K(x_i, x_j)
\end{equation}

\textbf{Step 4: 经典 SVM 求解}

使用经典 SVM 求解优化问题：
\begin{equation}
\max_\alpha \sum_i \alpha_i - \frac{1}{2} \sum_{i,j} \alpha_i \alpha_j y_i y_j K_{ij}
\end{equation}

约束条件：
\begin{equation}
\sum_i \alpha_i y_i = 0, \quad \alpha_i \geq 0
\end{equation}

\textbf{Step 5: 预测}

对于新样本 $x$，预测标签：
\begin{equation}
f(x) = \text{sign}\left(\sum_{i \in SV} \alpha_i y_i K(x_i, x) + b\right)
\end{equation}

\subsection{几何解释}

量子 SVM 在量子态空间中找到最大间隔超平面。量子核函数将数据映射到高维 Hilbert 空间，使得线性不可分的数据变得线性可分。

在 Bloch 球上，量子特征映射将经典数据编码为量子态的旋转角度，量子核函数计算两个量子态的重叠度。

\section{代码详解}

\begin{verbatim}
from quonic.ml import qsvm

# qsvm(data, labels, kernel, C)
# data: 训练数据，形状为 (n_samples, n_features)
# labels: 标签，形状为 (n_samples,)
# kernel: 核函数类型 ('quantum', 'rbf', 'poly')
# C: 正则化参数

result = qsvm(
    data=[[0, 1], [1, 0], [1, 1], [0, 0]],
    labels=[0, 1, 1, 0],
    kernel='quantum',
    C=1.0
)

# result.accuracy: 准确率
# result.support_vectors: 支持向量
# result.dual_coef: 对偶系数
# result.intercept: 截距
print(f'Accuracy: {result.accuracy}')
print(f'Support vectors: {result.support_vectors}')
\end{verbatim}

\section{进阶用法}

\subsection{场景 1：XOR 问题（量子核的优势）}

XOR 问题是经典线性 SVM 无法解决的，但量子 SVM 可以：

\begin{verbatim}
from quonic.ml import qsvm
import numpy as np

# XOR 数据：线性不可分
data = [[0, 0], [0, 1], [1, 0], [1, 1]]
labels = [0, 1, 1, 0]  # XOR 标签

# 经典 RBF 核 SVM（可能失败）
result_classic = qsvm(data, labels, kernel='rbf')
print(f'Classic SVM accuracy: {result_classic.accuracy}')

# 量子核 SVM（利用高维特征空间）
result_quantum = qsvm(data, labels, kernel='quantum')
print(f'Quantum SVM accuracy: {result_quantum.accuracy}')

# 量子核将数据映射到 4 维 Hilbert 空间
# 在高维空间中，XOR 数据变得线性可分
\end{verbatim}

\subsection{场景 2：手写数字识别（实际应用）}

\begin{verbatim}
from quonic.ml import qsvm
from quonic.datasets import load_digits

# 加载手写数字数据集
digits = load_digits(n_classes=2)  # 二分类：0 vs 1
X_train, X_test = digits.data[:100], digits.data[100:]
y_train, y_test = digits.target[:100], digits.target[100:]

# 降维到 4 维（减少量子比特数）
from sklearn.decomposition import PCA
pca = PCA(n_components=4)
X_train_pca = pca.fit_transform(X_train)
X_test_pca = pca.transform(X_test)

# 训练量子 SVM
result = qsvm(X_train_pca.tolist(), y_train.tolist(), kernel='quantum')

# 预测
predictions = result.predict(X_test_pca.tolist())
accuracy = sum(p == t for p, t in zip(predictions, y_test)) / len(y_test)
print(f'Test accuracy: {accuracy}')
\end{verbatim}

\section{适用场景}

\subsection{金融风控}

量子 SVM 可以用于金融欺诈检测。传统 SVM 在高维交易数据上训练慢，量子 SVM 可以利用量子核函数在更高维的空间中分类，捕捉复杂的欺诈模式。例如，信用卡交易数据有数百个特征（金额、时间、地点、商户类型等），量子 SVM 可以自动学习这些特征之间的非线性关系。

\subsection{药物发现}

量子 SVM 可以用于药物分子活性预测。分子描述符（如指纹、拓扑指数）通常是高维稀疏向量，量子核函数可以有效捕捉分子结构的细微差异。例如，预测分子是否与特定靶点结合，传统方法需要手动设计特征，量子 SVM 可以自动学习分子表示。

\subsection{图像识别}

量子 SVM 可以用于图像分类任务。虽然深度学习在图像识别上更流行，但量子 SVM 在小样本场景下可能更有优势。例如，医学图像分析中，标注数据稀缺，量子 SVM 可以利用量子核函数在有限数据上达到更好的分类精度。

\subsection{材料科学}

量子 SVM 可以用于材料性质预测。材料的电子结构、力学性质等可以用高维特征向量表示，量子核函数可以捕捉材料结构与性质之间的复杂映射关系。例如，预测新材料的超导转变温度，传统方法计算量大，量子 SVM 可以提供更快的预测。

\section{常见问题}

\subsection{量子 SVM 的优势是什么？}

量子 SVM 可以在指数维的 Hilbert 空间中计算核函数，这是经典核函数无法做到的。对于某些问题，量子 SVM 提供指数加速。

\subsection{量子 SVM 的精度如何？}

量子 SVM 的精度取决于：
\begin{itemize}
  \item 量子特征映射的选择
  \item 数据的质量和数量
  \item 正则化参数 C 的选择
\end{itemize}

\subsection{量子 SVM 需要多少量子比特？}

量子 SVM 需要的量子比特数取决于特征维度。对于 $d$ 维特征，需要 $\lceil \log_2(d) \rceil$ 个量子比特。

\subsection{量子 SVM 和经典 SVM 有什么区别？}

量子 SVM 使用量子核函数，可以在更高维的空间中计算核矩阵。经典 SVM 使用经典核函数（如 RBF 核），受限于有限的核函数类型。

\subsection{量子 SVM 的训练时间如何？}

量子 SVM 的训练时间包括：
\begin{itemize}
  \item 量子核矩阵计算：$O(N^2 \cdot T_{\text{circuit}})$
  \item 经典 SVM 求解：$O(N^3)$
\end{itemize}

其中 $T_{\text{circuit}}$ 是量子电路的执行时间。
