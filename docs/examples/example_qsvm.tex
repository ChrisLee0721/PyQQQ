\section{为什么需要？}

量子 SVM 利用量子核函数进行分类。

\subsection{经典局限}
\begin{itemize}
  \item 经典 SVM 核函数计算慢
  \item 对于高维数据，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子 SVM 可以在高维特征空间中分类
  \item 核函数计算更快
  \item 可以处理更复杂的数据
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 分类
  \item 模式识别
  \item 量子机器学习
\end{itemize}

\subsection{数学推导}

量子核函数：
\begin{equation}
K(x_i, x_j) = |\langle\phi(x_i)|\phi(x_j)\rangle|^2
\end{equation}

\subsection{几何解释}

量子 SVM 在量子态空间中分类数据。
