\section{为什么需要？}

量子强化学习是经典强化学习的量子推广，用于在量子环境中学习最优策略。

\subsection{经典局限}
\begin{itemize}
  \item 经典强化学习在高维状态空间中学习慢
  \item 对于复杂环境，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子强化学习可以利用量子叠加探索更大的状态空间
  \item 学习速度更快
  \item 可以处理更复杂的环境
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 游戏 AI
  \item 机器人控制
  \item 量子控制
\end{itemize}

\section{代码详解}

\begin{verbatim}
from quonic.ml import qrl

# qrl(env, n_episodes, learning_rate)
# env: 环境
# n_episodes: 训练轮数
# learning_rate: 学习率
result = qrl(env='gridworld', n_episodes=100)

# result.reward: 累积奖励
# result.policy: 学习到的策略
# result.history: 训练历史
print(f'Reward: {result.reward}')
\end{verbatim}
