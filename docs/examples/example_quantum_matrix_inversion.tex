\section{为什么需要？}

量子矩阵求逆是 HHL 算法的核心组件，用于求解线性方程组。

\subsection{经典局限}
\begin{itemize}
  \item 经典矩阵求逆需要 $O(N^3)$ 时间
  \item 对于大规模矩阵，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子矩阵求逆需要 $O(\text{poly}(\log N))$ 时间
  \item 对于稀疏矩阵，提供指数加速
  \item 是量子机器学习的基础
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 线性方程组求解
  \item 量子机器学习
  \item 量子模拟
\end{itemize}

\subsection{数学推导}

量子矩阵求逆估计 $A^{-1}$：
\begin{equation}
A^{-1} = \sum_i \frac{1}{\lambda_i} |v_i\rangle\langle v_i|
\end{equation}

\textbf{算法步骤}：
\begin{enumerate}
  \item 用 QPE 估计 $A$ 的本征值 $\lambda_i$
  \item 用受控旋转将本征值取倒数 $1/\lambda_i$
  \item 用逆 QPE 恢复量子态
\end{enumerate}

\subsection{几何解释}

量子矩阵求逆在量子态空间中操作，通过 QPE 将矩阵对角化，然后取倒数得到逆矩阵。
