\section{为什么需要？}

误差缓解是近期量子计算的关键技术，用于减少噪声对计算结果的影响。

\subsection{经典局限}
\begin{itemize}
  \item 经典计算没有量子噪声
  \item 量子噪声会破坏计算结果
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 误差缓解可以在不增加量子比特的情况下减少噪声
  \item 适用于近期量子设备
  \item 是量子纠错的补充
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 量子化学
  \item 量子优化
  \item 量子机器学习
\end{itemize}

\subsection{数学推导}

零噪声外推（ZNE）：
\begin{equation}
\langle O\rangle_{\text{mitigated}} = \text{extrapolate}(\langle O\rangle_{\lambda_1}, \langle O\rangle_{\lambda_2}, \ldots)
\end{equation}

其中 $\lambda_i$ 是噪声水平。

\subsection{几何解释}

误差缓解通过在多个噪声水平下测量，拟合并外推到零噪声极限。

\section{常见问题}

\subsection{误差缓解和量子纠错有什么区别？}

误差缓解在软件层面减少噪声，量子纠错在硬件层面纠正错误。误差缓解不需要额外的量子比特。

\subsection{误差缓解的精度如何？}

精度取决于噪声水平和缓解方法。ZNE 通常可以将误差减少一个数量级。
