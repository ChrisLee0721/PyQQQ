\section{Why do we need it?}

Quantum Fourier Transform (QFT) is the core component of quantum algorithms.

\subsection{Classical Limitations}
\begin{itemize}
  \item Classical FFT: $O(N \log N)$ time complexity
  \item For $N=2^n$, classical needs $O(n 2^n)$ operations
\end{itemize}

\subsection{Quantum Advantages}
\begin{itemize}
  \item QFT: $O(n^2)$ time complexity (exponential speedup)
  \item Core of quantum phase estimation, Shor's algorithm
  \item Can efficiently compute discrete Fourier transform
\end{itemize}

\subsection{Real-world Applications}
\begin{itemize}
  \item Quantum Phase Estimation (QPE)
  \item Shor's Algorithm (factoring)
  \item Quantum Simulation (Hamiltonian simulation)
\end{itemize}

\subsection{Mathematical Derivation}

QFT transforms computational basis to Fourier basis:
\begin{equation}
QFT|j\rangle = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} e^{2\pi ijk/N} |k\rangle
\end{equation}

For $n$ qubits, QFT decomposes as:
\begin{equation}
QFT = (H \otimes R_2 \otimes R_3 \otimes \cdots \otimes R_n) \cdot \text{CNOT gates}
\end{equation}

Where $R_k = \begin{pmatrix} 1 & 0 \\ 0 & e^{2\pi i/2^k} \end{pmatrix}$

\subsection{Geometric Interpretation}

On the Bloch sphere, QFT rotates computational basis states to Fourier basis. Each qubit's phase encodes frequency information.

\end{verbatim}

\subsection{Scenario 2: QFT for Phase Estimation}

\begin{verbatim}
# QFT for phase estimation
# Prepare eigenstate
qgate(X, 3)
# Apply controlled-U gates
qgate(CU, 0, 3)
qgate(CU, 1, 3)
qgate(CU, 2, 3)
# Apply inverse QFT
qgate(H, 2)
qgate(Rz(-math.pi/2), 1)
qgate(Rz(-math.pi/4), 0)
qshow()
\end{verbatim}

\section{FAQ}

\subsection{What's the difference between QFT and classical FFT?}

QFT is a quantum algorithm with $O(n^2)$ time complexity; classical FFT is $O(N \log N)$. QFT provides exponential speedup.

\subsection{How many qubits does QFT need?}

QFT needs $n$ qubits to process $N=2^n$ data points.

\subsection{What is the output of QFT?}

QFT output is the Fourier transform of the input state, encoded as a quantum state.
