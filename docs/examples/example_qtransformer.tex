\section{为什么需要？}

量子 Transformer 是经典 Transformer 的量子推广。

\subsection{经典局限}
\begin{itemize}
  \item 经典 Transformer 训练慢
  \item 对于长序列，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子 Transformer 可以处理长序列
  \item 训练速度更快
  \item 可以提取更复杂的特征
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 自然语言处理
  \item 序列建模
  \item 量子机器学习
\end{itemize}

\section{快速上手}

\begin{verbatim}
from quonic.ml import qtransformer
result = qtransformer(data=[[0,1],[1,0]], n_heads=2)
print(f'Output: {result.output}')
\end{verbatim}

\textbf{预期输出}：
\begin{verbatim}
Output: [0.5, 0.5]
\end{verbatim}

\subsection{数学推导}

量子注意力：
\begin{equation}
\text{Attention}(Q,K,V) = \text{softmax}(QK^T/\sqrt{d_k})V
\end{equation}

\subsection{几何解释}

量子 Transformer 在量子态空间中处理序列数据。

\section{代码详解}

\begin{verbatim}
from quonic.ml import qtransformer

# qtransformer(data, n_heads)
# data: input data
# n_heads: number of attention heads

print(f'Output: {result.output}')
\end{verbatim}
