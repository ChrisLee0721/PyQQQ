\section{Why do we need it?}

Finding a target in an unsorted database requires $O(N)$ queries classically, but Grover's algorithm only needs $O(\sqrt{N})$.

\subsection{Classical Limitations}
\begin{itemize}
  \item Classical search: worst case requires traversing all $N$ elements
  \item For $N=10^6$, classical needs $10^6$ queries, quantum only $10^3$
\end{itemize}

\subsection{Quantum Advantages}
\begin{itemize}
  \item Quadratic speedup: $O(\sqrt{N})$ vs $O(N)$
  \item Significant speedup for large-scale search problems
  \item Foundation for many quantum algorithms (amplitude amplification, quantum counting)
\end{itemize}

\subsection{Real-world Applications}
\begin{itemize}
  \item Database search
  \item Cryptography (searching key space)
  \item Optimization problems (finding optimal solutions)
  \item SAT solving
\end{itemize}

\subsection{Mathematical Derivation}

\textbf{Step 1: Initialization}

Apply $H$ gate to all qubits, creating uniform superposition:
\begin{equation}
|\psi_0\rangle = \frac{|00\rangle + |01\rangle + |10\rangle + |11\rangle}{2}
\end{equation}

\textbf{Step 2: Oracle Marking}

Oracle flips the phase of target state $|11\rangle$:
\begin{equation}
|\psi_1\rangle = \frac{|00\rangle + |01\rangle + |10\rangle - |11\rangle}{2}
\end{equation}

\textbf{Step 3: Diffusion Operator}

Diffusion operator reflects about the mean amplitude:
\begin{itemize}
  \item Mean amplitude = $(1/4 + 1/4 + 1/4 - 1/4)/4 = 1/8$
  \item After reflection: $|11\rangle$ amplitude is amplified
\end{itemize}

\textbf{Step 4: Iteration}

Repeat Oracle + Diffusion, each iteration amplifies target state amplitude.

\textbf{Step 5: Measurement}

Optimal iterations $\approx \pi\sqrt{N}/4$, target state probability $\approx 100\%$.

\subsection{Geometric Interpretation}

Grover's algorithm in Bloch sphere: each iteration rotates the quantum state, amplifying the target state amplitude.

Like swinging on a swing — each push increases the amplitude.

\section{FAQ}

\subsection{What is the speedup of Grover search?}

Quadratic speedup: $O(\sqrt{N})$ vs $O(N)$. For $N=10^6$, classical needs $10^6$ queries, quantum only $10^3$.

\subsection{How many iterations does Grover search need?}

Optimal iterations $\approx \pi\sqrt{N}/4$. For $N=4$ (2 qubits), only 1 iteration needed.

\subsection{Can Grover search find all targets?}

Grover search finds one target. To find all targets, multiple runs are needed.

\subsection{What are the limitations of Grover search?}

1) Need target state description; 2) Only finds one target; 3) For small problems, classical may be faster.

\subsection{What's the difference between Grover search and amplitude amplification?}

Grover search is amplitude amplification with uniform initial state. Amplitude amplification is more general, supports arbitrary initial states.
