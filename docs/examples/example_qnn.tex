\section{为什么需要？}

量子神经网络是经典神经网络的量子推广。

\subsection{经典局限}
\begin{itemize}
  \item 经典神经网络训练慢
  \item 对于高维数据，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子神经网络可以表示任意函数
  \item 训练速度更快
  \item 可以处理指数维的特征空间
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 分类
  \item 回归
  \item 强化学习
\end{itemize}
