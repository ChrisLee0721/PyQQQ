\section{为什么需要？}

Deutsch-Jozsa 算法是第一个证明量子计算优势的算法。

\subsection{经典局限}
\begin{itemize}
  \item 经典算法需要 $2^{n-1}+1$ 次查询才能确定函数类型
  \item 对于 $n$ 量子比特，经典需要指数次查询
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item Deutsch-Jozsa 只需要 1 次查询
  \item 提供指数加速
  \item 是量子算法设计的范例
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 量子算法教学
  \item 量子优势验证
  \item 量子计算理论
\end{itemize}

\subsection{数学推导}

Deutsch-Jozsa 算法判断函数 $f: \{0,1\}^n \to \{0,1\}$ 是常数还是平衡的。

\textbf{Step 1: 初始化}
\begin{equation}
|\psi_0\rangle = |0\rangle^{\otimes n}|1\rangle
\end{equation}

\textbf{Step 2: Hadamard 门}
\begin{equation}
|\psi_1\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle \cdot \frac{|0\rangle - |1\rangle}{\sqrt{2}}
\end{equation}

\textbf{Step 3: Oracle 查询}
\begin{equation}
|\psi_2\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} (-1)^{f(x)} |x\rangle \cdot \frac{|0\rangle - |1\rangle}{\sqrt{2}}
\end{equation}

\textbf{Step 4: Hadamard 门和测量}

如果测量结果是 $|0\rangle^{\otimes n}$，函数是常数的；否则是平衡的。

\subsection{几何解释}

Deutsch-Jozsa 算法利用量子叠加态同时查询所有输入，通过干涉效应判断函数类型。

\section{常见问题}

\subsection{Deutsch-Jozsa 算法的加速比是多少？}

指数加速：经典需要 $2^{n-1}+1$ 次查询，量子只需要 1 次。

\subsection{Deutsch-Jozsa 算法有什么实际应用？}

Deutsch-Jozsa 主要用于教学和理论研究，实际应用有限。

\subsection{Deutsch-Jozsa 算法的局限性是什么？}

Deutsch-Jozsa 只能判断函数是常数还是平衡的，不能处理其他类型的函数。
