\subsection{数学推导}

Oracle 标记目标态：
\begin{equation}
O|x\rangle = (-1)^{f(x)}|x\rangle
\end{equation}

其中 $f(x) = 1$ 当 $x$ 是目标态。

\textbf{矩阵表示}：
\begin{equation}
O = I - 2|t\rangle\langle t|
\end{equation}

\subsection{几何解释}

Oracle 在 Bloch 球上翻转目标态的相位。这相当于绕 Z 轴旋转 $\pi$。

\section{代码详解}

\begin{verbatim}
from quonic.algorithms import oracle

# oracle(function, n_qubits)
# function: 经典函数 f(x) -> {0, 1}
# n_qubits: 量子比特数

O = oracle(lambda x: x == '11', n_qubits=2)

# O: Oracle 矩阵
print(f'Oracle: {O}')
\end{verbatim}
