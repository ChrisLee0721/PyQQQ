\section{为什么需要？}

量子卷积神经网络是经典 CNN 的量子推广。

\subsection{经典局限}
\begin{itemize}
  \item 经典 CNN 训练慢
  \item 对于高维数据，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子 CNN 可以处理指数维的特征空间
  \item 训练速度更快
  \item 可以提取更复杂的特征
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 图像识别
  \item 模式分类
  \item 量子机器学习
\end{itemize}

\subsection{数学推导}

量子卷积：
\begin{equation}
U_{conv} = \prod_i U_i(\theta)
\end{equation}

\textbf{量子池化}：
\begin{equation}
U_{pool} = \text{CNOT}_{i,j}
\end{equation}

\subsection{几何解释}
