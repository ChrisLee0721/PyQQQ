\section{为什么需要？}

HHL 算法用于求解线性方程组 $Ax=b$，提供指数加速。

\subsection{经典局限}
\begin{itemize}
  \item 经典算法（如高斯消元）需要 $O(N^3)$ 时间
  \item 对于大规模稀疏矩阵，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item HHL 算法需要 $O(\text{poly}(\log N))$ 时间
  \item 对于稀疏矩阵，提供指数加速
  \item 是量子机器学习的基础
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 线性方程组求解
  \item 量子机器学习
  \item 量子模拟
\end{itemize}

\subsection{数学推导}

HHL 算法求解 $Ax=b$：
\begin{equation}
|x\rangle = A^{-1}|b\rangle
\end{equation}

\textbf{算法步骤}：
\begin{enumerate}
  \item 用 QPE 估计 $A$ 的本征值
  \item 用受控旋转将本征值取倒数
  \item 用逆 QPE 恢复量子态
  \item 测量得到解 $|x\rangle$
\end{enumerate}

\textbf{复杂度}：
\begin{equation}
O(\text{poly}(\log N) \cdot \kappa^2 / \epsilon)
\end{equation}

其中 $\kappa$ 是条件数，$\epsilon$ 是精度。

\subsection{几何解释}

HHL 算法在量子态空间中操作，通过 QPE 将矩阵对角化，然后取倒数得到解。
