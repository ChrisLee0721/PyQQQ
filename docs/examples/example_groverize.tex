\section{为什么需要？}

Groverize 是将任意 Oracle 自动转换为 Grover 搜索的工具。

\subsection{经典局限}
\begin{itemize}
  \item 手动构造 Grover 搜索电路复杂
  \item 需要理解 Oracle 和 Diffusion 算子
  \item 容易出错
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item Groverize 自动构造 Grover 搜索电路
  \item 只需要提供 Oracle
  \item 自动计算最优迭代次数
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 数据库搜索
  \item 组合优化
  \item 密码学分析
\end{itemize}

\section{快速上手}

\begin{verbatim}
from quonic.algorithms import groverize

# 自动构造 Grover 搜索
oracle = lambda x: x == '11'
result = groverize(oracle, n_qubits=2)
print(f'Found: {result.found}')

\subsection{数学推导}

Groverize 自动构造 Grover 搜索：
\begin{equation}
G = D \cdot O
\end{equation}

其中 $O$ 是 Oracle，$D$ 是 Diffusion 算子。

\textbf{最优迭代次数}：
\begin{equation}
k \approx \frac{\pi}{4} \sqrt{N}
\end{equation}

\subsection{几何解释}

Groverize 在 Bloch 球上旋转量子态，每次迭代放大目标态的振幅。

\section{代码详解}

\begin{verbatim}
from quonic.algorithms import groverize

# groverize(oracle, n_qubits, iterations)
# oracle: Oracle 函数
# n_qubits: 量子比特数
# iterations: 迭代次数（默认自动计算）

result = groverize(
    oracle=lambda x: x == '11',
    n_qubits=2,
    iterations='auto'
)

# result.found: 找到的目标态
# result.probability: 成功概率
# result.circuit: 量子电路
print(f'Found: {result.found}')
\end{verbatim}

\section{进阶用法}

\subsection{场景 1：不同 Oracle}

\begin{verbatim}
from quonic.algorithms import groverize

# 不同 Oracle
oracle1 = lambda x: x == '101'  # 精确匹配
oracle2 = lambda x: x.count('1') > 1  # 条件匹配
oracle3 = lambda x: int(x, 2) > 5  # 数值比较

for oracle in [oracle1, oracle2, oracle3]:
    result = groverize(oracle, n_qubits=3)
    print(f'Found: {result.found}')
\end{verbatim}

\subsection{场景 2：多目标搜索}

\begin{verbatim}
from quonic.algorithms import groverize

# 多目标搜索
oracle = lambda x: x in ['00', '11']
result = groverize(oracle, n_qubits=2)
print(f'Found: {result.found}')
\end{verbatim}

\section{常见问题}

\subsection{Groverize 和 Grover 搜索有什么区别？}

Groverize 是自动化的 Grover 搜索。只需要提供 Oracle，Groverize 会自动构造电路。

\subsection{Groverize 的精度如何？}

精度取决于迭代次数。自动计算的迭代次数通常能达到 99\% 以上的成功概率。
