\section{为什么需要？}

Trotter 分解用于近似哈密顿量演化。

\subsection{数学推导}

Trotter 分解：
\begin{equation}
e^{-i(A+B)t} \approx (e^{-iAt/n} e^{-iBt/n})^n
\end{equation}

\subsection{几何解释}

Trotter 分解在量子态空间中近似演化。

\section{代码详解}

\begin{verbatim}
from quonic.simulation import trotter

# trotter(H, t, n_steps)
# H: Hamiltonian matrix
# t: evolution time
# n_steps: number of Trotter steps
result = trotter(H=[[1,0],[0,-1]], t=1.0, n_steps=10)
print(f'Evolution: {result.evolution}')
\end{verbatim}
