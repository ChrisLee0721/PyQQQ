\section{为什么需要？}

量子隐形传态可以在不直接传输量子比特的情况下传输量子态。这是量子通信的核心协议。

\subsection{经典局限}
\b\begin{itemize}
  \item 经典通信无法传输量子态（不可克隆定理禁止复制未知量子态）
  \item 直接传输量子比特容易受噪声和退相干影响
\end{itemize}

\subsection{量子优势}
\b\begin{itemize}
  \item 使用纠缠和经典通信传输量子态，不违反不可克隆定理（原始态被销毁）
  \item 保真度可以接近 100\%
  \item 是量子网络和分布式量子计算的基础
\end{itemize}

\subsection{实际应用}
\b\begin{itemize}
  \item 量子网络（量子互联网的基础协议）
  \item 分布式量子计算（在不同量子处理器之间传输态）
  \item 量子密钥分发（E91 协议的基础）
\end{itemize}

\subsection{数学推导}

\textbf{Step 1: 准备态}

Alice 有 $q_0$ 处于态 $|\psi\rangle = \cos(\pi/6)|0\rangle + \sin(\pi/6)|1\rangle$

\textbf{Step 2: 创建 Bell 对}

Alice 和 Bob 共享 Bell 对：
\begin{equation}
|\Phi^+\rangle_{12} = \frac{|00\rangle + |11\rangle}{\sqrt{2}}
\end{equation}

\textbf{Step 3: Alice 的操作}

Alice 对 $q_0$ 和 $q_1$ 执行 CNOT 和 $H$ 门。

\textbf{Step 4: 测量}

Alice 测量 $q_0$ 和 $q_1$，得到 2 个经典比特 $(a, b)$，有 4 种可能：
\b\begin{itemize}
  \item $(0,0)$: $q_2 = |\psi\rangle$（无需校正）
  \item $(0,1)$: $q_2 = X|\psi\rangle$（需施加 $X$ 门）
  \item $(1,0)$: $q_2 = Z|\psi\rangle$（需施加 $Z$ 门）
  \item $(1,1)$: $q_2 = XZ|\psi\rangle$（需施加 $X$ 和 $Z$ 门）
\end{itemize}

\textbf{Step 5: Bob 的校正}

Bob 根据 Alice 的测量结果校正 $q_2$。

\textbf{Step 6: 结果}

$q_2$ 现在处于态 $|\psi\rangle$，完成了量子态的传输。

\subsection{几何解释}

量子隐形传态的几何解释：
\begin{enumerate}
  \item Alice 有 $|\psi\rangle$，想传给 Bob
  \item Alice 和 Bob 共享 Bell 对
  \item Alice 执行 Bell 测量
  \item Bob 根据结果校正
  \item Bob 得到 $|\psi\rangle$
\end{enumerate}

\section{代码详解}

\begin{lstlisting}[style=python]
import math
from quonic import qgate, qshow
from quonic.gates import CX, CZ, H, Ry

# Step 1: Prepare state to teleport
qgate(Ry(math.pi / 3), 0)  # q0 = cos(pi/6)|0> + sin(pi/6)|1>

# Step 2: Create Bell pair
qgate(H, 1)      # q1 -> (|0>+|1>)/sqrt(2)
qgate(CX, 1, 2)  # q1,q2 -> (|00>+|11>)/sqrt(2)

# Step 3: Alice's operations
qgate(CX, 0, 1)  # CNOT(q0, q1)
qgate(H, 0)       # H(q0)

# Step 4: Bob's corrections
qgate(CX, 1, 2)  # CNOT(q1, q2)
qgate(CX, 0, 2)  # CNOT(q0, q2)
qgate(CZ, 0, 2)  # CZ(q0, q2)

qshow()
\end{lstlisting}

\section{常见问题}

\subsection{隐形传态能超光速通信吗？}

不能。隐形传态需要经典通信来传输测量结果，经典通信受光速限制。

\subsection{隐形传态会违反不可克隆定理吗？}

不会。隐形传态会销毁原始态，所以不违反不可克隆定理。

\subsection{隐形传态需要多少量子比特？}

需要 3 个量子比特：1 个要传输的态 + 2 个 Bell 对。
