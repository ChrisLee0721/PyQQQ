\section{为什么需要？}

振幅放大是 Grover 搜索的推广，用于放大目标态的振幅。

\subsection{经典局限}
\begin{itemize}
  \item 经典搜索需要 $O(N)$ 次查询
  \item 对于大规模问题，经典方法效率低
  \item 经典算法无法利用量子并行性
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 振幅放大只需要 $O(\sqrt{N})$ 次查询
  \item 提供二次加速
  \item 是许多量子算法的基础
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 数据库搜索
  \item 优化问题
  \item 量子算法设计
\end{itemize}

\subsection{数学推导}

\textbf{Step 1: 初始态}

对所有量子比特施加 $H$ 门，创建均匀叠加态：
\begin{equation}
|\psi_0\rangle = H^{\otimes n}|0\rangle^{\otimes n} = \frac{1}{\sqrt{N}} \sum_{x=0}^{N-1} |x\rangle
\end{equation}

其中 $N = 2^n$。

\textbf{Step 2: Oracle 算子}

Oracle 算子标记目标态：
\begin{equation}
O|x\rangle = \begin{cases} -|x\rangle & \text{if } x = \text{target} \\ |x\rangle & \text{otherwise} \end{cases}
\end{equation}

可以写为：
\begin{equation}
O = I - 2|t\rangle\langle t|
\end{equation}

其中 $|t\rangle$ 是目标态。

\textbf{Step 3: 扩散算子}

扩散算子关于平均振幅反射：
\begin{equation}
D = 2|\psi_0\rangle\langle\psi_0| - I
\end{equation}

可以分解为：
\begin{equation}
D = H^{\otimes n} (2|0\rangle\langle 0| - I) H^{\otimes n}
\end{equation}

\textbf{Step 4: 振幅放大算子}

振幅放大算子：
\begin{equation}
Q = D \cdot O
\end{equation}

\textbf{Step 5: 迭代}

应用 $Q$ 算子 $k$ 次：
\begin{equation}
|\psi_k\rangle = Q^k |\psi_0\rangle
\end{equation}

最优迭代次数：
\begin{equation}
k \approx \frac{\pi}{4} \sqrt{N}
\end{equation}

\textbf{Step 6: 测量概率}

测量后目标态的概率：
\begin{equation}
P(t) = \sin^2((2k+1)\theta)
\end{equation}

其中 $\sin\theta = 1/\sqrt{N}$。

\subsection{几何解释}

振幅放大在 Bloch 球上旋转量子态。每次迭代都放大目标态的振幅，同时减小其他态的振幅。

在二维子空间中，初始态 $|\psi_0\rangle$ 和目标态 $|t\rangle$ 张成一个平面。振幅放大算子在这个平面上旋转量子态。

\section{进阶用法}

\subsection{场景 1：数据库搜索（实际应用）}

在无序数据库中搜索特定记录：

\begin{verbatim}
from quonic.algorithms import amplitude_amplification
import random

# 模拟数据库：1000 条记录，搜索特定 ID
database_size = 1000
target_id = 42  # 要搜索的目标

# 经典搜索：需要 O(N) 次查询
classic_queries = 0
for i in range(database_size):
    classic_queries += 1
    if i == target_id:
        break
print(f'Classic search: {classic_queries} queries')

# 量子搜索：只需要 O(sqrt(N)) 次查询
n_qubits = 10  # 2^10 = 1024 > 1000
target_binary = format(target_id, f'0{n_qubits}b')

result = amplitude_amplification(
    target=target_binary,
    n_qubits=n_qubits,
    iterations=int(3.14159/4 * (database_size**0.5))  # 最优迭代次数
)
print(f'Quantum search: {result.iterations} iterations')
print(f'Found with probability: {result.probability:.4f}')

# 量子加速：从 42 次查询减少到约 25 次迭代
\end{verbatim}

\subsection{场景 2：多目标搜索}

\end{verbatim}

\subsection{场景 3：量子计数与振幅估计}

结合量子相位估计进行精确计数：

from quonic.algorithms import amplitude_amplification, amplitude_estimation
import numpy as np

# 估计数据库中满足条件的记录数
n_qubits = 6  # 64 条记录
target = '101010'  # 目标

# 使用振幅估计精确计算目标态概率
est_result = amplitude_estimation(
    target=target,
    n_qubits=n_qubits,
    precision=4  # 4 位精度
)

# 计算目标态数量
total_states = 2**n_qubits
target_count = int(est_result.estimate * total_states)

print(f'Total states: {total_states}')
print(f'Estimated target states: {target_count}')
print(f'Estimation error: {est_result.error:.4f}')

# 应用：量子计数可以用于估计优化问题的解空间大小
\end{verbatim}

\section{适用场景}

\subsection{无序数据库搜索}

振幅放大可以用于在无序数据库中搜索目标。例如，在 100 万条记录中查找特定用户，经典方法平均需要 50 万次查询，振幅放大只需要约 1000 次。这对于大规模数据检索、搜索引擎等应用非常重要。

\subsection{组合优化问题}

振幅放大可以用于求解组合优化问题。例如，旅行商问题、调度问题等，经典方法需要遍历所有可能的解，振幅放大可以更快地找到最优解。这对于物流优化、资源分配等应用非常重要。

\subsection{密码学分析}

振幅放大可以用于密码学分析。例如，搜索密钥空间、破解哈希函数等，经典方法需要指数时间，振幅放大可以提供二次加速。这对于评估密码系统的安全性非常重要。

\subsection{量子算法基础}

振幅放大是许多量子算法的基础，如 Grover 搜索、量子计数、量子最小值查找等。理解振幅放大是学习更高级量子算法的前提。

\section{常见问题}

\subsection{振幅放大和 Grover 搜索有什么区别？}

Grover 搜索是振幅放大在均匀初始态下的特例。振幅放大更通用，支持任意初始态。

\subsection{振幅放大的加速比是多少？}

二次加速：$O(\sqrt{N})$ vs $O(N)$。

\subsection{振幅放大的最优迭代次数是多少？}

最优迭代次数 $k \approx \frac{\pi}{4} \sqrt{N}$。

\subsection{振幅放大的精度如何？}

振幅放大的精度取决于迭代次数。最优迭代次数下，目标态的概率接近 100\%。
