\section{为什么需要？}

振幅放大是 Grover 搜索的推广，用于放大目标态的振幅。

\subsection{经典局限}
\begin{itemize}
  \item 经典搜索需要 $O(N)$ 次查询
  \item 对于大规模问题，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 振幅放大只需要 $O(\sqrt{N})$ 次查询
  \item 提供二次加速
  \item 是许多量子算法的基础
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 数据库搜索
  \item 优化问题
  \item 量子算法设计
\end{itemize}

\subsection{数学推导}

振幅放大算子：
\begin{equation}
Q = -A S_0 A^{-1} S_\chi
\end{equation}

其中 $S_0$ 翻转初始态的相位，$S_\chi$ 翻转目标态的相位。

\textbf{迭代}：
\begin{equation}
|\psi_k\rangle = Q^k |\psi_0\rangle
\end{equation}

最优迭代次数 $k \approx \pi\sqrt{N}/4$。

\subsection{几何解释}

振幅放大在 Bloch 球上旋转量子态，每次迭代都放大目标态的振幅。

\section{常见问题}

\subsection{振幅放大和 Grover 搜索有什么区别？}

Grover 搜索是振幅放大在均匀初始态下的特例。振幅放大更通用，支持任意初始态。

\subsection{振幅放大的加速比是多少？}

二次加速：$O(\sqrt{N})$ vs $O(N)$。
