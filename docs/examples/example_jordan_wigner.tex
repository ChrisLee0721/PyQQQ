\section{为什么需要？}

Jordan-Wigner 变换将费米子算符映射到量子比特算符。

\subsection{经典局限}
\begin{itemize}
  \item 经典方法无法高效处理费米子系统
  \item 对于大系统，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item Jordan-Wigner 变换可以在量子比特上表示费米子系统
  \item 提供指数加速
  \item 是量子化学的基础
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 量子化学
  \item 材料科学
  \item 量子物理
\end{itemize}

\subsection{数学推导}

Jordan-Wigner 变换：
\begin{equation}
a_j^\dagger \to \frac{X_j - iY_j}{2} \otimes Z_{j-1}
\end{equation}

\textbf{费米子算符}：
\begin{equation}
\{a_i, a_j^\dagger\} = \delta_{ij}
\end{equation}

\subsection{几何解释}

Jordan-Wigner 变换在量子比特空间中表示费米子系统。
