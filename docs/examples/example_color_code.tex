\section{为什么需要？}

颜色码是拓扑量子纠错码，具有高容错阈值。

\subsection{经典局限}
\begin{itemize}
  \item Shor 码和 Steane 码的容错阈值较低
  \item 对硬件连接性要求高
  \item 经典纠错码不能直接用于量子系统
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 颜色码有最高的容错阈值（约 1\%）
  \item 只需要最近邻连接
  \item 适合二维量子处理器
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 量子计算（容错量子计算）
  \item 量子通信（保护量子态）
  \item 量子存储（延长相干时间）
\end{itemize}

\subsection{数学推导}

\textbf{Step 1: 三色格子}

颜色码使用三色格子结构：
\begin{itemize}
  \item 红色面：X 校验子
  \item 绿色面：Z 校验子
  \item 蓝色面：X 校验子
\end{itemize}

\textbf{Step 2: 校验子测量}

X 校验子：
\begin{equation}
S_X = \prod_{i \in \text{face}} X_i
\end{equation}

Z 校验子：
\begin{equation}
S_Z = \prod_{i \in \text{face}} Z_i
\end{equation}

\textbf{Step 3: 错误检测}

通过测量校验子检测错误：
\begin{equation}
S_X |\psi\rangle = \pm |\psi\rangle
\end{equation}

如果测量结果是 $-1$，说明检测到错误。

\textbf{Step 4: 错误纠正}

根据校验子测量结果纠正错误：
\begin{equation}
|\psi'\rangle = C \cdot E |\psi\rangle = |\psi\rangle
\end{equation}

其中 $C$ 是纠正算子，$E$ 是错误算子。

\textbf{Step 5: 容错阈值}

容错阈值：
\begin{equation}
p_{\text{threshold}} \approx 1\%
\end{equation}

当物理错误率低于阈值时，逻辑错误率随码距指数衰减。

\subsection{几何解释}

颜色码在二维格子上编码量子信息，通过测量局部校验子来检测和纠正错误。

三色格子结构允许并行测量校验子，提高了纠错效率。

\section{代码详解}

\begin{verbatim}
from quonic.qec import color_code

# color_code(distance, error_rate)
# distance: 码距
# error_rate: 物理错误率

result = color_code(distance=3, error_rate=0.01)

# result.logical_error_rate: 逻辑错误率
# result.threshold: 容错阈值
# result.qubit_count: 量子比特数
# result.syndrome: 校验子
print(f'Logical error rate: {result.logical_error_rate}')
print(f'Threshold: {result.threshold}')
print(f'Qubit count: {result.qubit_count}')

\section{常见问题}

\subsection{颜色码和表面码有什么区别？}

颜色码使用三色格子，表面码使用方格。颜色码有更好的阈值。

\subsection{颜色码需要多少量子比特？}

需要 $O(d^2)$ 个量子比特，其中 $d$ 是码距。

\subsection{颜色码的容错阈值是多少？}

约 1\%，是目前最高的。
