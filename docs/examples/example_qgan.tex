\section{为什么需要？}

量子 GAN 是经典 GAN 的量子推广。

\subsection{经典局限}
\begin{itemize}
  \item 经典 GAN 训练不稳定
  \item 对于复杂数据，经典方法效率低
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 量子 GAN 可以生成量子态和经典数据
  \item 训练更稳定
  \item 可以生成更复杂的数据
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 生成模型
  \item 数据增强
  \item 量子机器学习
\end{itemize}

\subsection{数学推导}

量子 GAN：
\begin{equation}
\min_G \max_D V(D,G)
\end{equation}

其中 $G$ 是生成器，$D$ 是判别器。

\subsection{几何解释}

量子 GAN 在量子态空间中生成数据。
