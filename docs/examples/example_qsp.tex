\subsection{数学推导}

量子信号处理：
\begin{equation}
U = e^{i\theta_0 Z} \prod_{k=1}^{d} W e^{i\theta_k Z}
\end{equation}

其中 $W$ 是信号算子，$\theta_k$ 是相位角度。

\subsection{几何解释}

量子信号处理在 Bloch 球上旋转量子态，通过相位角度实现任意多项式变换。

\section{代码详解}

\begin{verbatim}
from quonic.algorithms import qsp

# qsp(polynomial, n_qubits)
# polynomial: 多项式系数
# n_qubits: 量子比特数
result = qsp(polynomial=[1, 0, -1], n_qubits=2)

# result.output: 输出态
# result.angles: 相位角度
print(f'Result: {result.output}')
\end{verbatim}
