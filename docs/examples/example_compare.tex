后端比较用于比较不同量子后端的性能。

\begin{itemize}

  \item 需要统一的比较方法

\subsection{数学推导}

后端比较：
\begin{equation}
\text{fidelity} = |\langle\psi_{\text{ideal}}|\psi_{\text{actual}}\rangle|^2
\end{equation}

\subsection{几何解释}

后端比较在 Bloch 球上比较不同后端的输出。保真度衡量实际输出与理想输出的接近程度。

\section{代码详解}

\begin{verbatim}
from quonic import compare

# compare(backends, circuit, shots)
# backends: 后端列表
# circuit: 量子电路
# shots: 测量次数

result = compare(
    backends=['native', 'qiskit'],
    circuit=circuit,
    shots=1024
)

# result: 各后端的保真度
print(f'Comparison: {result}')
\end{verbatim}
