\subsection{数学推导}

\textbf{Step 1: 噪声模型}

量子噪声可以用量子通道描述：
\begin{equation}
\mathcal{E}(\rho) = \sum_k E_k \rho E_k^\dagger
\end{equation}

其中 $E_k$ 是 Kraus 算子，满足 $\sum_k E_k^\dagger E_k = I$。

\textbf{Step 2: 比特翻转噪声}

比特翻转噪声：
\begin{equation}
E_0 = \sqrt{1-p} I, \quad E_1 = \sqrt{p} X
\end{equation}

\begin{equation}
\mathcal{E}_{\text{bf}}(\rho) = (1-p)\rho + p X\rho X
\end{equation}

\textbf{Step 3: 相位翻转噪声}

相位翻转噪声：
\begin{equation}
E_0 = \sqrt{1-p} I, \quad E_1 = \sqrt{p} Z
\end{equation}

\begin{equation}
\mathcal{E}_{\text{pf}}(\rho) = (1-p)\rho + p Z\rho Z
\end{equation}

\textbf{Step 4: 退极化噪声}

退极化噪声：
\begin{equation}
\mathcal{E}_{\text{dep}}(\rho) = (1-p)\rho + \frac{p}{3}(X\rho X + Y\rho Y + Z\rho Z)
\end{equation}

\textbf{Step 5: 退相干噪声}

退相干噪声：
\begin{equation}
\mathcal{E}_{\text{dc}}(\rho) = (1-p)\rho + p|0\rangle\langle 0|\rho|0\rangle\langle 0|
\end{equation}

\subsection{几何解释}

量子噪声在 Bloch 球上使量子态退相干。比特翻转噪声绕 X 轴旋转，相位翻转噪声绕 Z 轴旋转，退极化噪声使量子态趋向混合态。

\section{进阶用法}

\subsection{场景 1：噪声对 Bell 态的影响}

分析噪声如何破坏量子纠缠：

\begin{verbatim}
from quonic.noise import noise_model
from quonic import qgate, qshow
from quonic.gates import H, CX
import numpy as np

# 创建 Bell 态
qgate(H, 0)
qgate(CX, 0, 1)

# 无噪声测量
result_clean = qshow(noise=0)
print(f'Clean Bell state: {result_clean.counts}')

# 不同噪声水平
for noise_rate in [0.01, 0.05, 0.1, 0.2]:
    result_noisy = qshow(noise=noise_rate)

    # 计算保真度
    # 理想 Bell 态：|00> 和 |11> 各 50%
    ideal_prob = {'00': 0.5, '11': 0.5}
    fidelity = sum(
        min(result_noisy.counts.get(s, 0)/1024, ideal_prob.get(s, 0))
        for s in ['00', '01', '10', '11']
    )

    print(f'Noise={noise_rate}: Fidelity={fidelity:.4f}')

# 分析：噪声破坏纠缠，使 Bell 态退化为混合态
# 当噪声率 > 11% 时，Bell 不等式不再被违反
\end{verbatim}

\subsection{场景 2：噪声缓解技术}

使用零噪声外推（ZNE）缓解噪声：

\begin{verbatim}
from quonic.noise import noise_model
from quonic.mitigation import zne
from quonic import qgate, qshow
from quonic.gates import H, CX

# 原始电路
def bell_circuit():
    qgate(H, 0)
    qgate(CX, 0, 1)

# 不同噪声水平下的测量结果
noise_levels = [0.0, 0.01, 0.02, 0.03]
expectation_values = []

for noise in noise_levels:
    result = qshow(noise=noise)
    # 计算 <Z0 Z1> 期望值
    prob_00 = result.counts.get('00', 0) / 1024
    prob_11 = result.counts.get('11', 0) / 1024
    expectation = prob_00 + prob_11  # |00> 和 |11> 的概率和
    expectation_values.append(expectation)

# 零噪声外推：拟合并外推到 noise=0
zne_result = zne(noise_levels, expectation_values)
print(f'ZNE mitigated value: {zne_result.extrapolated:.4f}')
print(f'Unmitigated value: {expectation_values[0]:.4f}')

# ZNE 的原理：
# 1. 在多个噪声水平下测量
# 2. 拟合噪声-期望值曲线
# 3. 外推到零噪声极限
\end{verbatim}

\subsection{场景 3：量子误差校正中的噪声建模}

在量子纠错码中建模噪声：

\begin{verbatim}
from quonic.noise import noise_model
from quonic.qec import bit_flip_code

# 比特翻转码的噪声分析
code = bit_flip_code(distance=3)

# 不同物理错误率
for p in [0.001, 0.01, 0.05, 0.1]:
    noise = noise_model(error_rate=p, noise_type='bit_flip')

    # 模拟纠错过程
    result = code.simulate(noise_model=noise, shots=1000)

    # 计算逻辑错误率
    logical_error_rate = result.logical_error_rate
    print(f'Physical error rate: {p}')
    print(f'Logical error rate: {logical_error_rate:.6f}')
    print(f'Suppression factor: {p/logical_error_rate:.2f}x')

# 分析：当物理错误率低于阈值时，
# 逻辑错误率随码距指数衰减
# 这就是容错量子计算的原理
\end{verbatim}

\section{适用场景}

\subsection{量子算法设计}

噪声模型可以指导量子纠错码的设计。不同的噪声类型（比特翻转、相位翻转、退极化）需要不同的纠错策略。

\subsection{量子硬件评估}

噪声模型可以评估量子硬件的质量。通过测量量子门的保真度，可以估计噪声率，这是评估硬件性能的关键指标。

\subsection{量子通信信道评估}

噪声模型可以评估量子通信信道的安全性。在量子密钥分发中，噪声率决定了密钥的安全性，高噪声率可能表示窃听。

\subsection{量子存储优化}

噪声模型可以预测量子态的退相干时间，帮助设计更好的量子存储方案。

\section{常见问题}

\subsection{量子噪声有哪些类型？}

比特翻转、相位翻转、退极化、退相干等。

\subsection{如何对抗量子噪声？}

使用量子纠错码或噪声缓解技术。

\subsection{量子噪声的来源是什么？}

量子噪声来自环境干扰、门误差、测量误差等。
