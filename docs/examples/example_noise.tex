\section{为什么需要？}

量子噪声是量子计算的主要挑战之一。

\subsection{经典局限}
\begin{itemize}
  \item 经典计算没有量子噪声
  \item 量子噪声会破坏量子信息
\end{itemize}

\subsection{量子优势}
\begin{itemize}
  \item 理解量子噪声可以设计更好的量子算法
  \item 量子纠错可以对抗噪声
  \item 噪声模型可以指导硬件设计
\end{itemize}

\subsection{实际应用}
\begin{itemize}
  \item 量子计算
  \item 量子通信
  \item 量子存储
\end{itemize}

\subsection{数学推导}

量子噪声模型：
\begin{equation}
\mathcal{E}(\rho) = (1-p)\rho + p/3 (X\rho X + Y\rho Y + Z\rho Z)
\end{equation}

\textbf{噪声类型}：
\begin{itemize}
  \item 比特翻转（X 错误）
  \item 相位翻转（Z 错误）
  \item 退相干
\end{itemize}

\subsection{几何解释}

量子噪声在 Bloch 球上使量子态退相干。

\section{代码详解}

\begin{verbatim}
from quonic.noise import noise_model

# noise_model(error_rate, noise_type)
# error_rate: probability of error

\end{verbatim}
