\subsection{数学推导}

哈密顿量模拟：
\begin{equation}
U(t) = e^{-iHt}
\end{equation}

\textbf{Trotter 分解}：
\begin{equation}
e^{-iHt} \approx \prod_k e^{-iH_k \Delta t}
\end{equation}

\subsection{几何解释}

哈密顿量模拟在量子态空间中演化。

\section{常见问题}

\subsection{哈密顿量模拟和动力学模拟有什么区别？}

哈密顿量模拟关注演化算子，动力学模拟关注态演化。

\subsection{哈密顿量模拟的精度如何？}

取决于 Trotter 分解的阶数。
