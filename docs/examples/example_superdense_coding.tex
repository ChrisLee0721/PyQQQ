\section{Why do we need it?}

Superdense coding uses 1 qubit to transmit 2 classical bits, an important quantum communication protocol.

\subsection{Classical Limitations}
\begin{itemize}
  \item Classical communication: 1 qubit can only transmit 1 classical bit
  \item Classical communication needs 2 channels to transmit 2 bits
\end{itemize}

\subsection{Quantum Advantages}
\begin{itemize}
  \item Superdense coding: 1 qubit transmits 2 classical bits
  \item Uses entanglement for information compression
  \item Foundation for quantum communication
\end{itemize}

\subsection{Real-world Applications}
\begin{itemize}
  \item Quantum Communication (efficient information transfer)
  \item Quantum Networks (quantum internet)
  \item Quantum Cryptography (quantum key distribution)

\subsection{Mathematical Derivation}

Superdense coding protocol:
\begin{enumerate}
  \item Alice and Bob share Bell pair $|\Phi^+\rangle = (|00\rangle + |11\rangle)/\sqrt{2}$
  \item Alice encodes 2-bit message:
  \begin{itemize}
    \item 00: no operation
    \item 01: apply $X$ gate
    \item 10: apply $Z$ gate
    \item 11: apply $ZX$ gate
  \end{itemize}
  \item Alice sends her qubit to Bob
  \item Bob decodes to get 2-bit message
\end{enumerate}

\subsection{Geometric Interpretation}

Superdense coding uses entanglement as a quantum channel. Alice's operations change the entanglement structure of the Bell pair, and Bob decodes to recover information.

\section{FAQ}

\subsection{Why can superdense coding transmit 2 bits?}

Superdense coding uses entanglement as a quantum channel. Alice's operations change the Bell pair's entanglement structure, and Bob decodes to recover 2 bits of information.

\subsection{What's the difference between superdense coding and teleportation?}

Superdense coding: 1 qubit transmits 2 classical bits. Teleportation: 2 classical bits transmit 1 qubit.

\subsection{How many qubits does superdense coding need?}

Superdense coding needs 2 qubits: 1 for Alice, 1 for Bob (shared Bell pair).
