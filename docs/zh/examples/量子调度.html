为什么需要？

量子调度用于优化量子门的执行顺序。

经典局限

  • 量子门的执行顺序会影响电路深度

  • 需要优化调度

量子优势

  • 量子调度可以减少电路深度

  • 提高执行效率

  • 减少噪声影响

实际应用

  • 量子编译

  • 电路优化

  • 硬件执行

快速上手

from quonic.compile import schedule

# 量子调度
result = schedule(circuit)
print(f'Scheduled circuit: {result.circuit}')
print(f'Depth: {result.depth}')

预期输出：

Scheduled circuit: ...
Depth: 3

原理详解

电路图

数学推导

量子调度： \[\begin{equation} \text{depth} = \max_i \text{layer}(i) \end{equation}\]

其中 \(\text{layer}(i)\) 是第 \(i\) 个门的层。

几何解释

量子调度在时间轴上安排量子门的执行顺序。目标是最小化电路深度。

代码详解

from quonic.compile import schedule

# schedule(circuit, method)
# circuit: 量子电路
# method: 调度方法 ('asap', 'alap', 'critical_path')

result = schedule(
    circuit=circuit,
    method='asap'
)

# result.circuit: 调度后的电路
# result.depth: 电路深度
# result.schedule: 调度表
print(f'Scheduled circuit: {result.circuit}')
print(f'Depth: {result.depth}')
