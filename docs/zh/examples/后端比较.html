为什么需要？

后端比较用于比较不同量子后端的性能。

经典局限

  • 不同后端有不同的性能特征

  • 需要统一的比较方法

量子优势

  • 后端比较可以帮助选择最佳后端

  • 用于性能基准测试

  • 指导硬件选择

实际应用

  • 性能基准测试

  • 硬件选择

  • 算法优化

快速上手

from quonic import compare

# 比较后端
result = compare(backends=['native', 'qiskit'], circuit=circuit)
print(f'Comparison: {result}')

预期输出：

Comparison: native: 0.99, qiskit: 0.98

原理详解

电路图

数学推导

后端比较： \[\begin{equation} \text{fidelity} = |\langle\psi_{\text{ideal}}|\psi_{\text{actual}}\rangle|^2 \end{equation}\]

几何解释

后端比较在 Bloch 球上比较不同后端的输出。保真度衡量实际输出与理想输出的接近程度。

代码详解

from quonic import compare

# compare(backends, circuit, shots)
# backends: 后端列表
# circuit: 量子电路
# shots: 测量次数

result = compare(
    backends=['native', 'qiskit'],
    circuit=circuit,
    shots=1024
)

# result: 各后端的保真度
print(f'Comparison: {result}')

适用场景

性能基准测试

后端比较用于性能基准测试。比较不同后端的保真度、速度等指标。

硬件选择

后端比较用于硬件选择。选择最适合特定任务的后端。

常见问题

后端比较的指标有哪些？

常见的指标包括：保真度、速度、噪声水平等。

如何选择最佳后端？

选择最佳后端需要考虑任务需求、硬件特性、成本等因素。
