# 高级特性

学习 QuoNic 的高级特性：条件分支、量子接口、量子数据类型等。

## 量子条件分支 (qif)

量子条件分支根据测量结果执行不同操作：

```python
from quonic import qgate, qif, qshow
from quonic.gates import H, X

# 量子条件分支
qgate(H, 0)
qif(0, lambda: qgate(X, 1))  # 如果 q0=1，则翻转 q1
qshow()
```

## 经典条件分支 (cif)

经典条件分支在量子程序中使用经典逻辑：

```python
from quonic import qgate, cshow
from quonic.gates import H

qgate(H, 0)
result = cshow()
if result == '0':
    print('Measured 0')
else:
    print('Measured 1')
```

## 经典循环 (cwhile)

经典循环在量子程序中使用迭代：

```python
from quonic import qgate, cshow
from quonic.gates import H

while True:
    qgate(H, 0)
    result = cshow()
    if result == '1':
        break
print('Got 1!')
```

## 量子整数 (qint)

量子整数是量子程序中的整数数据类型：

```python
from quonic import qint

# 量子整数
a = qint(3, n_bits=4)
b = qint(5, n_bits=4)
c = a + b
print(f'Result: {c}')  # 8
```

## 量子接口 (qi)

量子接口是 QuoNic 的核心 API：

```python
from quonic import qgate, qshow, reset
from quonic.gates import H, CX

# 施加量子门
qgate(H, 0)
qgate(CX, 0, 1)

# 测量并显示
qshow()

# 重置
reset()
```

## Oracle 构造

Oracle 是量子算法的核心组件：

```python
from quonic.algorithms import oracle

# 构造 Oracle
f = lambda x: x == '11'
O = oracle(f, n_qubits=2)
print(f'Oracle: {O}')
```

## 门分解

门分解将高级量子门分解为基本门：

```python
from quonic.compile import decompose

# 门分解
gate = [[1, 0], [0, complex(0, 1)]]
result = decompose(gate, basis=['cx', 'u3'])
print(f'Decomposed: {result.gates}')
```
