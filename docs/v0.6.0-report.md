## 二、电路优化 pass

### 2.1 三种优化策略

| Pass | 原理 | 示例 |
|---|---|---|
| **cancel** | 相邻自逆门对消掉 | X·X→I, H·H→I, CX·CX→I |
| **commute** | 可交换门重排，让可消减门靠在一起 | H(0)·CX(0,1)·H(0) → H(0)·H(0)·CX(0,1) → CX(0,1) |
| **peephole** | 已知模式替换 | CX(0,1)·CX(1,0)·CX(0,1) → SWAP(0,1) |

### 2.2 统一入口

```python
from quonic import optimize

optimized = optimize(circuit)  # 默认：cancel → commute → cancel → peephole
optimized = optimize(circuit, passes=("cancel",))  # 只跑消减
```

### 2.3 实现细节

- `optimize_cancel`：遍历 ops 列表，相邻同名同比特自逆门对跳过
- `optimize_commute`：bubble-sort 风格，可交换门左移寻找消减机会
- `optimize_peephole`：3 门模式匹配（CX·CX·CX → SWAP）
- 默认序列 `("cancel", "commute", "cancel", "peephool")` — commute 后再跑一次 cancel

### 2.4 测试

9 个测试：X·X=I、H·H=I、CX·CX=I、commute 带消减、CX·CX·CX→SWAP、空电路、非门操作保留。

## 三、qif 多比特 + 嵌套

### 3.1 多比特门

```python
# Controlled-CX = Toffoli
qif(0).then(CX, 1, 2).else_(I, 1, 2)  # → GateOperation("ccx", (0,1,2))

# Controlled-SWAP = Fredkin
qif(0).then(SWAP, 1, 2).else_(I, 1, 2)  # → CX·CCX·CX 分解

# Controlled-CZ = MCZ
qif(0).then(CZ, 1, 2).else_(I, 1, 2)  # → GateOperation("mcz", (0,1,2))
```

### 3.2 特例分解

| 输入 | 分解 |
|---|---|
| controlled-CX | CCX（Toffoli） |
| controlled-CZ | MCZ |
| controlled-SWAP | CX·CCX·CX（Fredkin） |
| controlled-CCX | MCZ（4比特） |
| else ≠ identity | NotImplementedError（通用受控 U 分解待实现） |

### 3.3 嵌套

```python
inner = qif(1).then(X, 2).else_(Z, 2)
outer = qif(0).then_ops(inner).else_ops(inner)
```

- `then_ops(ops)` / `else_ops(ops)` 接受子电路操作列表
- `_compile_nested()` 构建子电路酉矩阵 → V = then_U · else_U† → 受控 V 分解
- 限制：子电路 ≤ 4 qubit（避免指数爆炸）

### 3.4 向后兼容

- `_check_branch`：qif 放开多比特，cif 仍限制单比特
- `controlled(gate, control, *targets)`：校验 target 数量，不匹配抛清晰错误
- 单比特路径完全不变

## 四、requires_grad + autodiff 调度

### 4.1 IR 扩展

```python
circuit = Circuit()
circuit.requires_grad = True  # 新属性，默认 False
```

### 4.2 调度器集成

```python
from quonic.scheduler import recommend_method, recommend_backend_autodiff

# requires_grad=True → 强制 statevector（autodiff 需要 SV）
recommend_method({"requires_grad": True, ...})  # → "statevector"

# 自动选最优 autodiff 后端
recommend_backend_autodiff({"n": 10})  # → pennylane
recommend_backend_autodiff({"n": 25})  # → tensorcircuit
```

### 4.3 qshow 集成

```python
qshow(requires_grad=True)  # 设置 circuit.requires_grad = True，调度器自动选
```

## 六、算法模板深化

### 6.1 QCNN（量子卷积神经网络）

| 维度 | v0.5.0 | v0.6.0 |
|---|---|---|
| 量子比特 | 2（固定） | 可配置 `n_qubits` |
| 层数 | 1（固定） | 可配置 `n_layers` |
| 结构 | Ry + CX | 卷积层（Ry + CX 梯子）+ 池化层 |
| 训练 | 无 | COBYLA 优化 + MSE 损失 |
| 输入 | 无 | 4 像素二值图像分类 |

### 6.2 QGAN（量子生成对抗网络）

| 维度 | v0.5.0 | v0.6.0 |
|---|---|---|
| 生成器 | 1 qubit Ry | 可配置 `n_qubits` + Ry + CX 梯子 |
| 判别器 | 简化阈值 | 经典判别器（阈值分类） |
| 训练 | 10 步手动更新 | 数值梯度 + 学习率 + 对抗训练 |
| 输出 | 损失值 | 最终分布 + 目标分布 + 训练参数 |

### 6.3 表面码

| 维度 | v0.5.0 | v0.6.0 |
|---|---|---|
| 距离 | 3（固定） | 可配置 `distance` |
| 数据比特 | 5（硬编码） | d²（动态） |
| syndrome | 4（硬编码） | d²-1（动态） |
| 解码 | 无 | 多数投票解码器 |
| 噪声 | 无 | 支持 `error_rate` 参数 |

## 九、技术债务

| 项 | 严重度 | 说明 |
|---|---|---|
| tensorcircuit numpy patch | 低 | 全局 patch，idempotent，上游修复后可删 |
| cqlib 不是模拟器 | 低 | 委托 native，无独立 GPU |
| qif 通用受控 U 分解 | 中 | 多比特 else ≠ identity 时 NotImplementedError |
| `_sv_*` 多比特门未向量化 | 中 | CuPy 引擎 CX/CCX 等用 Python 循环 |
| entanglement 启发式 | 低 | treewidth/n 比率可能不准 |
