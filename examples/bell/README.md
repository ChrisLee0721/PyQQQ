# Bell state 贝尔态

H(0) 后 CNOT(0,1) 把 |00> 变成最大纠缠态 (|00>+|11>)/√2 —— 量子计算最经典的起点。

H(0) then CNOT(0,1) turns |00> into the maximally entangled state (|00>+|11>)/√2 — the classic starting point of quantum computing.

## 运行 Run

```bash
python examples/bell/bell.py
```

## 预期输出 Expected output

约 50% 的 |00> 和 50% 的 |11>，从不出现 |01> 或 |10>。

Roughly 50% |00> and 50% |11>; |01> and |10> never appear.
