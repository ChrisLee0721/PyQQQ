# GHZ state GHZ 态

H(0) 后 CNOT(0,1)、CNOT(1,2) 得到三比特最大纠缠 (|000>+|111>)/√2。

H(0) then CNOT(0,1), CNOT(1,2) gives the 3-qubit maximally entangled state (|000>+|111>)/√2.

## 运行 Run

```bash
python examples/ghz/ghz.py
```

## 预期输出 Expected output

约 50% 的 |000> 和 50% 的 |111>。

Roughly 50% |000> and 50% |111>.
